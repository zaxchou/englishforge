# 54 · 四科分别怎么学：新东方讲义研读与本地课程整合规划

2026-10-02｜规划补充 v0.1｜继承53真题驱动私人老师方向；本文件细化分科教学与视频课程管理。用户已授权将自有课程在个人本地NAS系统中学习，当前仅规划，未开发播放器、未部署、未观看视频。

## 1. 这次修正：共享学习记录，分别设计四科

“先独立完成小题组，再老师复盘”是默认介入时机，不是四科同一套教学法。读、听、说、写要有各自的操作、训练分支、反馈和成长指标。尤其口语要再分听后重复与采访，写作要再分组句、邮件和学术讨论。

课程也不能仅由一道题的错误触发。系统要提供有组织的方法课，学生能先学一种办法，再在原题中运用；已有基础则先挑战，卡住后补讲。一次复盘只修一两个重点，避免把所有训练工具强塞进每道题。

结构建议为：**老师课程教方法 → 托福原题练运用 → AI针对本人反馈 → 另一道原题检查 → 计划调整。** 用户既可按科目课程逐步学，也可从今天推荐任务进入，不把课程强制刷完作为做题前置条件。

## 3. 讲义让规划发生的具体变化

1. 阅读不是长句分析一条线。还包括词形和搭配补全、日常文本扫读、证据与推断、局部修辞作用、整篇结构。
2. 听力不是一句一句听写到背下全部内容。先有情境和整段意义，再对真正阻碍理解的声音/关系补练。
3. 口语不是把录音转写后检查关键词。听后重复训练准确保持原句，采访训练自发组织观点；发音、意群、例子和回应分别处理。
4. 写作不是AI改到高级。先审清交际任务和题目限制，再让本人形成内容，随后讨论组织与语言。
5. 词汇不是新增一套每天从头背的词表。记得字形、听到能及时懂、表达时能调用是不同状态；本人当前材料里的障碍词优先。
6. 讲义的方法课和视频可以成为真正的教学资源，系统无需把所有老师讲解都重新生成一遍。AI负责将方法用到本人的具体问题上。

## 4. 阅读课：理解层次与做题效率一起练

依据：阅读上册PDF7页填词方法、17/23页日常文本定位与略读、39/44–45页词义与主干、49页逻辑关系；下册1/5页推断、16–17/22页插句衔接、33–34/40页修辞、46/51/56页段落与主旨。这里均为PDF页面序号，不能与印刷页混用。

### 三种不同任务

- **补全单词：** 先独立填完整段；复盘区分词形拼写、词性句法、搭配与上下文意义。老师按实际错位展示哪种线索起作用，不能只给中文词义。
- **日常文本：** 给完整通知、邮件、帖子等真实版式；学生读题并定位关键信息。复盘对照找到的证据与选项，区分“读错内容”和“定位浪费时间”。不把每篇短通知强制拆句分析。
- **学术篇章：** 完成关联题后按需要进入词义、长句、段落功能、推断或插句复盘。先知道作者在说什么，再说明哪个细节支持哪个结论。

### 界面与老师

主区是可选中、高亮的原文及题组；复盘可切“看证据 / 拆这句话 / 看段落关系”。选中长句之后，逐层显示主线、修饰、连接；日常定位题则只圈关键日期、对象、动作或条件。所有标注是教学辅助，原文始终可回看。

增长观察包括新题正确率、完成时间、定位证据准确性、必要支持及任务覆盖。不能以扫读更快直接宣布理解更好，也不能把能翻译整句当所有阅读技能都学会。

## 5. 听力课：先听意思，再修真正的卡点

依据：听力PDF9/13–14页概念—定义—举例；23页交际功能；29–32页对话；37–40页公告；43页讲座结构；66–67页语气；听口基础PDF3–8页的整段理解→缺口填听→语言回顾→自己的意见。

### 四种任务各有重点

- **听一句选回应：** 识别问题/请求/态度和场景，判断合适回应。不是听到一个相同单词就选对应选项。
- **短对话：** 人物在讨论什么、误会在哪里、谁打算做什么。整段首听后完成小题组，复盘再回放关键话轮。
- **公告：** 抓目的、变化、具体要求和应做行动，不以记住所有字词为训练出口。
- **学术谈话：** 保持主题、概念解释、例子作用、比较/因果和下一步发展；可在复盘绘制一张极简信息图，而不是把每个句子都写成笔记。

### 错因分支

| 观察 | 先怎样区分 | 下一步训练 |
|---|---|---|
| 单词不认识 | 看稿后仍不懂 | 解释语境词义，必要时查词，回到原段 |
| 单词认识但首听认不出 | 显稿后立即懂；关键短段听辨再试 | 原声片段、意群、弱读连读与少量听写/跟读 |
| 每句似懂却记不住关系 | 无稿说出整体意思，再对照结构 | 主题与关系保持，短信息重建，逐步延长材料 |
| 听到内容却选错意图 | 对照上下话轮与选项差异 | 语用、习惯表达、说话目的与语气 |
| 主要因时间紧张 | 看清首听/限时差异，听取本人感受 | 渐减辅助、按任务限时；不把紧张一律归为词汇差 |

允许跳过个别不懂词继续听，先保住整段；精听只处理值得修的片段。听写是工具，不是每题必经考核。首听与重听效果分别记录；最终仍需另一段未见原音检验。

## 6. 口语课：两条完全不同的练法

### A. 听后重复

依据：口语上册PDF7–10页意群和结构、11–13页易错音、23–25页发音、33–36页听后重复练习；下册38页听—复—核—改—再复。精学时可以看稿分块，但测评首次必须无稿。

流程：完整听一句→独立录一次→回放自己的录音→核对漏词/变词及可懂度→聚焦一处原声练习→完整再录→之后用新句检查。长句逐渐增加长度与结构，不以同一句重复十遍当十次独立进步。

**边界：** 讲义上册PDF29–30页建议遇到障碍词用上位词改说。这可作为表达策略讨论，但不能把同义改写算成准确重复。ETS要求这类任务尽量准确重复原句；正式量表也区分准确重复与只保留意思。系统分别显示内容准确性与可懂度，不能以ASR逐字结果代替声学判断。[ETS口语说明](https://www.ca.ets.org/en/toefl/test-takers/ibt/about/content/speaking.html)

### B. 采访回答

依据：上册PDF37–41页题型和直接回应、46–48页具体例子；下册6–8页列举细节、20–22页比较与让步、26/30页方案及分情况讨论。

流程：听懂原问题→无准备独立回答→先检查是否回应问题、听者能否跟上→找出一个空泛/断裂/语言卡顿点→老师追问一个具体细节或解释理由→本人再录→另一问题无稿回答检验。

练法要按问题选：描述用具体细节；选择用立场和理由；经历用关键过程；开放问题可给方案；复杂问题可说明条件。不是每题都固定“立场＋两理由＋例子＋让步”，也不强迫复杂词句。

界面需录音回放、可疑转写位置、片段反馈与前后版本。采访的内容改进不能同时被计为听后重复准确度，两个子能力独立显示。

## 7. 写作课：组句、邮件、讨论分别设计

依据：写作PDF11页组句分析，14–16页邮件组成，18–19页改写与语域，28–30页请求，35–36页问题/解决方案，38–46页讨论审题与结构，48–71页五类论证。

- **组句：** 核心成分、上下文、搭配和嵌套关系共同约束。用原词块与槽位完成，不让AI另外补词改题。错误反馈指出具体结构问题与意义影响。
- **邮件：** 首次写完整邮件；反馈先看对象、目的、题目要求和请求是否清晰，然后处理组织、礼貌程度和语言。允许选择一段重写，不默认AI整篇代写。
- **学术讨论：** 先独立写第一稿；老师对照教授的问题和其他回应检查扣题与自己的贡献，再看论点是否有解释、具体例子或清楚的条件。因果、例证、对比、让步、分类是备选工具，不是每篇都必须具备。

写作空间保留原任务、第一稿、老师评论和本人修改对比。AI建议可采纳或拒绝，本人能说明改动目的。时间分配在练习中可渐减，限时检查关闭补全/翻译/润色。

成长作品重点展示“一个原来不清楚的请求现在读者能直接回应”“一个泛泛的理由现在有具体支撑”，不能只显示字数增加或AI改了多少处。

## 8. 怎样吸收讲义，而不照抄口诀

讲义是教学经验来源，考试规则以当前ETS材料为准，具体语法依实际语境核验。

- 听力“主旨通常在开头”“转折后更重要”保留为关注线索，不能生成机械判题规则。
- 阅读反向推断要受原文支持；“之前不在大学”不必然推出“之前一定是高中生”，不能把二选一练习包装成普遍逻辑。
- 写作建议150–180词、鼓励让步或积累万能理由属于教学策略，不变成必须字数、必须结构的官方评分要求。
- 写作PDF11页的时态建议需保留语境边界；过去提问不要求后文所有事件机械改成过去。
- 初查范文中可见拼写/形式疑点，需看原页分清原文、OCR和用于展示的有缺陷样本；不能将“高分范文”标签当每句都无误。
- 口语意群按意义、语流和实际听者处理，不在每个主语与谓语之间强行插停顿。
- 旧听口讲义明确来自Task 5。可复用理解问题、方案、表达意见的步骤，但列为基础补课，不作为当前iBT口语题型。

张俊杰帮助解释语言如何组织；新东方讲义帮助建立分科练法；原题让我们观察本人实际能否运用。三者各负其责，不让一个老师的框架替代全部考试方法。

## 9. 本地视频在系统里怎样学

增加“课程”资源入口，并在今天任务/老师复盘中链接相关课。课程页包含科目、章节、对应讲义、继续播放、笔记/疑问、看后要做的原题或练习。用户也能自主顺序看课，不只能等AI推荐。

默认日常：先独立做原题组→老师识别困难→必要时推荐对应方法课→观看或读讲义→回到补练。第一次完全陌生的题型，可先看不含当前原题答案的导学。看了包含同题讲评的视频，该题必须标记已接触，不能再进入独立测评。

播放记录与能力状态分开：

- 保存最近播放位置、速度、最后播放时间、章节的实际观看区间以及本人完成/跳过选择。
- 向后拖到结尾不能当全部看完，反复看同一段也不扩大独立覆盖率。
- “看过/完成课”是学习活动；“能在新题运用”需要练习证据。
- 切设备或刷新继续播放；笔记绑视频位置及讲义PDF页；当前不猜逐段时间戳。
- 同一知识点已会时允许免修；看课与练题都不靠次数强行放行。

### NAS播放的待开发条件

当前文件都是MOV后缀；只对听力导学一份读取编码元数据，没有播放：H.264视频＋AAC音频，约868.84秒。证据见 [video-probe-sample.json](toefl-redesign/lecture-notes/video-probe-sample.json)。不能据这一份保证206份在浏览器中都能播。

开发前抽样不同科目/大小文件检查容器和编码及目标浏览器。若编码兼容而容器影响播放，优先生成MP4衍生版重封装；不兼容再按需转码，保留原文件、不一次重做全部视频。浏览器兼容由容器与编码共同决定。[MDN媒体格式](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Containers)

通过本地NAS服务的媒体接口提供视频，支持Range请求以便拖动和续播；不直接用Windows盘符充当手机可播放地址。进度存NAS数据库，与账号隔离，可备份恢复；不只存在一个浏览器。[MDN Range请求](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests)

稳定媒体ID映射文件，改名/移目录不会让进度丢失。仅开放选定教材目录，文件路径不接受任意客户端拼接；未完成下载或文件损坏显示具体原因。当前仍是个人本地用途，不需要为多人平台设计商业分发功能。

AI读讲义与判断本人回答可能涉及云模型；个人NAS部署不自动意味着模型调用也在本地。技术选型时明确只发送需要的段落和本人选择发送的录音，不默认上传整套教材/视频。

## 10. 原型及后续工作的顺序更新

53中的原型范围继续有效，但不再以一条听力样板推定四科体验成立。需要四个有区别的代表流程：

1. 阅读：原文定位＋一个长句/推断复盘分支。
2. 听力：无稿首听＋声音/关系分支＋原音补练。
3. 口语：听后重复准确核对与采访展开，两种任务切换。
4. 写作：邮件或讨论第一稿→针对评论本人修改；组句另有操作样板。
5. 视频：续播＋对应讲义＋看后回到练习；显示观看进度和能力证据的区别。

下一轮先补全关键方法页的可检索文字与章节映射，核验样板原题音频，然后做四科可点原型。优先让本人走通并判断是否像一门好课程；确认后再冻结接口、数据库、模型与正式开发合同。

当前还欠：讲义中图像文本全量识别、所有练习答案校对、视频与讲义完整章节对应、原题音频逐段校对、口语/写作量表与反馈真实验收、本人原型试学。已完成材料研读不能替代这些工作。
