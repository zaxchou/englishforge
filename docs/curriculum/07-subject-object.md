## 1. 目标（用可观察行为表述）

在**简单主动陈述句**里：

1. 给定人物关系描述（谁对谁做动作），能选出正确形式的句子（He helps her. ✔ / Her helps he. ✘）；
2. 给定一句英文，能判断动作主体是谁、动作对象是谁；
3. 人物关系反转（A 帮 B → B 帮 A）后，能改出新句而不是背原句；
4. 在词块支持下能独立组出句子；在减少提示后能用句子说 / 写出来；
5. 换人物、换动词、换场景后仍能做到 1–3；隔日仍能做到 1–3（延迟检索）。

## 2. 边界（明确不做什么）

**不推广的结论：**

- 不说"主语永远是动作发出者"——被动句（第 14 课）、there be、形式主语等结构另有规则；本目标只在主动句内成立。
- 不做"格 / case / 语法人称"的术语考核；张老师的表述是"动作主体 / 动作对象"，判定与讲解沿用该表述。
- 不涉及反身代词（myself 等，第 08 课）、物主代词（my / mine，s3 另有合同）、三单形式规律（likes / beats，s4 另有合同）。例句中出现的三单、词形变化不归入本目标计错。

**范围外（收录但单独标注复核，不默认进正式路径）：**

- `c-s2-13`（She and I are students.）——并列主语规则是独立小知识点，标 scopeNote 单独审核；
- `c-s2-16`（It's me.）——口语固定用法与正式语法（It is I）存在差异，标 scopeNote 单独审核；
- 介词后宾格（第 14 课内容）不提前引入。

## 4. 前置知识与支持策略

- 前置：认识人称代词（你我他 / 我们你们他们）；认识少量高频动词。
- 受控动词表（8 个）：**help、call、tell、find、like、love、see、thank**；课稿原例动词 beat 仅用于"我打他 / 他打我"对照原型。
- 人物卡名字固定：**Tom、Mia、Ben、Anna**（跨任务复现，减少认知负担）。
- 例句含三单（helps / calls）或词形变化时：**先提供词块**（supportLevel ≥ 2），不把三单错误记为本题主宾格错误（目标归属原则）。
- 生词不认识的错误记为 `vocab-blocked`，不计入语法错误；超词表词汇须给出释义或替换。

## 5. 常见错误与错误标签（errorTags）

| 标签 | 现象 | 对应提示方向 |
|---|---|---|
| `role-reversed` | 角色颠倒：Her helps he. / He helps him.（对象用成主格） | 回看人物关系：谁做动作、动作落在谁身上 |
| `case-form` | 形式选错：I love she. / Me love her. | 对比同一人物在动作前后的两种形式（I↔me） |
| `referent-unclear` | 短文里 him / her 指谁说不清 | 回到上一句找被替代的人物 |
| `vocab-blocked` | 不认识动词或名词而卡住 | 给出释义或替换，不计语法错误 |
| `third-person-distractor` | 因三单形式（beats/likes）分心导致错 | 单独说明词块已提供，回到目标本身（**不作为主宾格错误**） |

## 6. 变式家族（variantGroupId 语义）

**规则：同一家族 = 同一结构与错误机制；换人名、换动词、换场景不新建家族。**

| 家族 ID | 结构与错误机制 |
|---|---|
| `so-he-him` | he/him 方向：第三人称男性做主体 / 做对象 |
| `so-she-her` | she/her 方向 |
| `so-they-them` | they/them 方向 |
| `so-we-us` | we/us 方向 |
| `so-reversal` | 角色反转构造：交换主宾后产出新句 |
| `so-referent` | 跨句指代（短文） |
| `so-listening` | 听辨人物关系 |
| `so-oral` | 少提示口头表达 |

保留题（holdout）沿用同结构家族（迁移检测要的是"同结构、没见过的例句"），通过 `assessmentRole: 'holdout'` 与曝光记录（`firstSeenAt` / `isFirstExposure`）与练习分离；用过一次即"已见"。

## 8. 教学比喻 vs 可直接判定的英语事实

| 课稿说法（引用） | 性质 | 对应的英语事实（判定依据） |
|---|---|---|
| "一个是感觉爽的，一个是感觉疼的" | **教学比喻**（帮助记角色） | 动作主体用主格（I / he / she / we / they），动作对象用宾格（me / him / her / us / them） |
| "他就是两个不同的人""都是张三……他俩心情也不一样" | **教学比喻**（强调形式必有区分的意义） | 同一指称对象在两种句法角色下使用不同词形（格形态对立）；与情绪无关 |
| "形式变化为了区分含义" | 课程总纲（学习策略） | 人称代词的格形态是英语事实；"必须为区分含义而变"是张老师的解释框架 |

**判定纪律：题目判定只看"形式与角色关系"，不得把比喻写进判题规则、选项反馈或正确性说明；比喻可在解析中作为理解辅助出现，并保持与事实同屏可区分。**

## 9. 成功行为与证据口径

- 客观题首发独立正确 → 进入能力证据（识别 / 理解维度）。
- 词块拼句完成 → 记"有提示表达"（supportLevel 2），不等于自由表达。
- 口头表达：无 AI 时只记"已尝试 / 自评完成"（未验证），识别文字匹配不算客观正确。
- 延迟保持：次日 / 第 7 天检索成功单独计数。
- 达标（供人工观察参考，非自动通关）：换人物方向后首次正确率 ≥80%（近 10 次合格首发作答）、跨 ≥2 训练日、≥3 个变式家族、识别与理解各有成功记录、无未处理关键错误。

## 10. 场景（首批限定）
