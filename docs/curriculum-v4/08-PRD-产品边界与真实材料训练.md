# PRD 对齐记录：产品边界与真实材料训练

2026-09-30｜与用户逐项对齐中｜不是已批准的完整 PRD｜不授权开发或部署

## 已确认的产品定位

本产品首先是一套能在站内完成、值得学习者主动投入时间的英语课程。核心价值是能力增长，不是计时、学习时长登记或替代番茄钟。现有背词、听力、阅读、Chunks 等工具可继续使用；无需先打通它们的 API，也不要求手动登记外部学习时间。站内练习时间可自然记录，但不得把时长当作掌握证据。

长远可以把听、读、说、写逐步整合到同一学习体验中。是否替代其他 App，取决于站内训练是否达到用户实际使用的效果；不能用“总入口”定位先行强迫迁移。

课程主线由结构能力目标和前置关系驱动，并用真实交流任务检验运用。独立表达是每节训练的出口：对已会的基础内容可免修；对新内容有简洁、讲清原理且注明边界的讲解。听懂、读懂是必要过程，但孤立识别、跟读或做对选择题不能独自代表会用。

## 内容的主次关系

主线要有系统编排、经校对的材料，保证语法范围与复杂度不断向前；专门编写但表达自然的素材和真实素材同时存在。真实素材从早期进入。个人选择的 AI、生活或专业领域 podcast/视频可进入个人迁移训练，但不替代主线的完整性责任，也不因某视频频繁出现某结构就改变课程前置关系。

“自然”指有情境、说话目的、听者预期与真实意义，包含正常语流中的省略、指代、语块和澄清。不能简单等同于更长句、更快语速、没有讲解或不受控地堆生词。成人学习者可以利用简洁显性的结构解释，再到语境中理解和运用；不照搬儿童零基础习得过程。

## 一个真实音频训练单元的合同

第一类例子是 1–2 分钟 AI 或生活 podcast 片段。片段长度是起步建议，不是每节固定时长，也不是必须把整期视频切成大量小题。片段应有足够上下文和一个可以回应的观点或问题。

1. **选材与校对**：标记来源、时间点、说话者、可播放条件、字幕来源与可靠性；核对片段是否适合当前目标，避免只按关键词匹配。核查访问条件和使用范围，不能假定所有视频音频都能下载、重发或长期缓存。
2. **首次理解**：先听原声且不预先显示完整字幕；要求概括大意、关系或说话者意图。回答可简短，不能用猜词数量当主要分数。
3. **针对性再听**：定位卡住的声音、词义、结构或篇章关系；允许片段循环、变速、逐级提示和查词。必要时再展示校对后的原文及精华解释。系统需区分“初听独立理解”和“看过原文后理解”。
4. **意义检查**：用少量有诊断价值的问题核对关键事实、逻辑和态度；不能仅由整段摘要自动生成表面阅读理解题。
5. **口头输出**：学习者录一段英文复述或回应，不照读原文；在相近但不同的情境中再尝试使用目标表达。站内录音、回放、文字修正与重录属于待实现能力，不能把现有视频工具误记为已经具备。
6. **反馈与成长证据**：先看听到的观点与逻辑是否准确，再看表达是否清楚、合适；目标结构、语音和流利度按实际需要处理。显示依据和不确定性，低置信转写不能给确定的能力结论。保留第一次独立尝试、提示后的尝试和新材料迁移，不能把重听同片段后的熟练当作已能听懂陌生材料。

初期完整体验的验收：学习者可以在站内从原声开始，经过必要帮助，完成理解与录音回应；其首次独立表现、帮助依赖和后来新片段的表现可比较。若素材字幕错误、问题答案不稳或音频不可播放，该单元不得认证能力。

## hanson / YouTube Digest 可复用边界

已只读检查同级 hanson 项目中的 video-learner/index.html、workers/video-learner-api/README.md、workers/video-learner-api/src/worker.js 和 docs/course-fusion-plan.md。它的后端说明为 youtube-digest Chrome 扩展接口的服务端移植，现有前端有 YouTube 嵌入播放、时间戳字幕、语义分段、定位、单段与 A/B 循环、变速和翻译；后端有字幕获取、分析/摘要、翻译、素材提交与草稿审核等接口。相关功能的运行条件和跨项目接入方式尚未验证。

可优先复用的是视频 ID/时间戳/字幕的数据处理、播放器交互、缓存、失败状态与人工审核思路。不能直接照搬其教学层：现有素材审核面向 AI 课程的知识补充和简短检查题，不等于英语能力目标选择、可听辨片段校对、口语录制、复述评价、迁移或掌握认证。未来的实现方案需先审计接口权限、部署边界、费用和对既有项目的影响，再决定复用代码、共享服务还是迁移设计。当前不修改 hanson。

- 口语录制、ASR 辅助、反馈可信度、存储与用户控制等需做可用性与成本验证；不先许诺“自动精准评分”。
- 真实材料的选段、字幕校对、审核、可用性及失败回退需要制作流程；内容供给能力需由实际产出和返工数据估算。
- 阶段出口需用学习者的原始听说读写样本与陌生任务验证，评分阈值仍是待校准初值。
