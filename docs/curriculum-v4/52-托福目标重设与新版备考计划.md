# 52 · 托福目标重设与新版备考计划

2026-10-02｜规划草案 v0.1｜用户已确认最终目标改为托福考试；目标分、单项要求、考试日期和基线尚待确认。当前仅修改规划，不将旧学习数据换算为托福分数，不实施考试判分或大批生成。

## 一、目标与旧计划的效力

第一目标改为：在确认的考试时间前，达到申请项目要求的托福总分与单项要求，并用未见、限时、无辅助的测评验证稳定表现。申请阶段、考试日期和成绩送达时间分别记录，不能把之前约18个月后的申请时间直接当作考试日期。

留学课堂、日常互动与艺术科技英语保留为长期用途。张俊杰的框架保留为理解含义、搭主线、组织关系与简化表达的方法，不再作为必须顺序走完的课程目录。托福没有独立的“语法科目”，语法学习应落到实际阅读、听力、组句和表达任务。

此前13/00及相关文档中的“课程不是托福应试”属于旧目标，已被本次决定覆盖。51号已改教学层可以复用；其下一步全范围扩展优先级调整为：先补覆盖考试任务所需的能力，不以完成全部72单元为考试前置条件。此前“完整知识图”与个体按需生成仍保留，服务于可解释的补弱。

## 二、确认中的四个条件

| 条件 | 当前事实 | 处理方式 |
|---|---|---|
| 考试时间 | 用户确认至少一年后考试，具体日期未定 | 不承诺几个月达标；收集首考窗口及申请截止日期 |
| 目标 | 未确认总分和单项要求 | 依据本人期望或目标项目官方要求；旧制目标保留原话，另记录新制要求 |
| 基线 | 四级通过，词汇量自估8000–10000，实际听说调用有卡顿；非托福测评分数 | 做符合新版任务的基线测评，不由词汇量/CET推算托福成绩 |
| 时间投入 | 此前每天3–4小时 | 先按3小时安排可调整训练；确认当前时间是否仍适用 |

## 四、个人备考路径：先诊断，再按缺口安排

### 阶段A：确定基线和任务理解

建议用第一周完成，而不是连续一周反复诊断。

1. 先认识所有新版任务及操作要求，短样题只作熟悉，不计为独立基线。
2. 用未练过的完整新版材料，在限时、无词典/字幕/提示/AI辅助下测评；如工具实际给出正规练习评分，记录来源、版本、日期和四项成绩。
3. 保存口语原音频和写作原文；将问题分别标为语言理解、声音识别/保持、表达组织、题型操作与时间控制。
4. 若只有纸面样题、没有评分模考，明确“未建立分数基线”，但可以建立分项任务表现。使用更合适的官方模考后再设分数差距。
5. 将之前做过的课程和已熟单词视为背景信息；不强迫从零重练，不用旧题作首次测评。

阶段出口是可解释的薄弱项与训练计划，不是几题后一个看起来精确的总分。

### 阶段B：基础能力与题型技能并行

阅读：按任务分别检查词形/语境补全、实用文本信息、学术段落结构与推断。长句训练通过“主线→修饰→关系”帮助理解，但也练信息定位、阅读速度和生词处理，不只分析语法。

听力：从听辨与即时回应逐步进入对话、通知和学术谈话。区分听不清、认识词但反应慢、记不住关系、误解说话意图；辅助练习可以重听看稿，之后用未见材料无辅助检验。跟读不能代替听力理解成绩。

口语：分别训练听后准确复述与采访式即时回答。跟读/模仿可保留，但不能只用已背的稿测表达；反馈分别看可懂度、内容回应、流畅组织和语言使用，不把ASR转写是否命中关键词当评分。

写作：分别练组句、邮件和学术讨论。先明确交际目的与内容，再做语言改进；保留限时第一稿，不只看AI修润后的成品。主谓、修饰、时间/状态和句子组合按具体问题补足。

每天至少触及输入与输出；薄弱项多分时间，强项保持。题型策略帮助完成任务，但不能靠模板遮盖理解或语言缺口。

### 阶段C：专项限时与整套整合

能在辅助练习完成之后，转入单项限时、新材料检验和整套训练。阶段B每1–2周安排一次未见任务的检查；阶段C可安排周度整套/分项组合，频率依据复盘所需时间调整。不是每天做整套又重复同一批题。

每次检查后决定：哪些错误需要原理补课，哪些需要语音/速度练习，哪些是题型操作问题。后续教学由后端按这些缺口安排，核心与验证题来自原题，AI按需提供讲解和反馈；保留正式模考材料供阶段检查，不能提前教答案。

### 阶段D：考前稳定性与正式考试

确切目标和日期确认后再定周数。考前关注新的可比材料中的四项稳定性、单项下限、疲劳和操作节奏；同时核查报名、证件、设备/考场与学校送分要求。一次超常表现不能视为稳达目标，不承诺结果。正式考试成绩是最终验收依据。

## 五、暂定每日3小时安排

这是训练安排建议，不是ETS要求；基线后按薄弱项调整，若现有时间变化则重排。

| 时间 | 内容 | 当日必须留下的东西 |
|---|---|---|
| 20分钟 | 词汇与chunks，优先当天材料中造成理解/表达障碍的内容 | 放进语境能理解或调用的例句，不仅新增词数 |
| 35分钟 | 阅读专项，三个任务类别轮换 | 限时首次表现及具体错因 |
| 45分钟 | 听力专项：首次理解→卡点补练→新材料验证 | 首听结果与辅助之后的变化分别保存 |
| 30分钟 | 口语，两类任务分开练 | 原始录音与下一次只改一两个关键点 |
| 30分钟 | 写作，组句/邮件/讨论按天轮换 | 第一稿、修改理由与不同题再写 |
| 20分钟 | 复盘与下一日调整 | 两三个优先缺口，避免所有错题都再刷一遍 |

休息放在这些学习块之间，不计入3小时净学习。若每天4小时，额外时间优先补当周最弱项目或完成阶段测评，不自动加一小时背词。不必先废掉现有听力/阅读软件；能提供新版有效材料和结果的工具继续使用。

## 六、系统新职责和开发顺序

现有课程不能只改标题叫“托福课”。教学层、作品、账户隔离、证据条件与按需生成可以复用；需要新增可核验的考试任务覆盖。

第一批：目标档案。记录考试版本、日期、目标及单项要求、基线来源/版本/日期与可用时间；没有分数时保留未测。首页明确“本周补什么、练哪个考试任务、为什么”。旧记录保留，不换算考试成绩。

第二批：建立新版任务矩阵与学习/测评两种模式。学习可提示/查词/重听；限时测评按已核验任务要求限制辅助。训练模式与评分来源必须显式存档；不能在同一道看过答案的题上测独立表现。

第三批：先交本人最弱项的完整闭环，再逐项覆盖全部任务。语言基础补课（含张俊杰框架）→具体题型练习→未见限时检验→作品与错因→后继课调整。按反馈生成的是教学内容，自制AI题不标成ETS真题；AI反馈不冒充官方分数。

第四批：接官方/可核验的模考结果及阶段趋势。没有公开API时手工录入来源与四项成绩，保留原报告引用；不伪造连接器或声称同步成功。自建能力数据与外部模考成绩分开显示。

第五批：倒排至考试窗口。考前阶段优先稳定薄弱单项与整套完成；普通兴趣播客、面试专项和72单元全量扩展不挤占备考主线。考后再回到长期学术与生活用途。
