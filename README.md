# TOEFL Lab · 托福自学练习

自用的托福备考系统：把个人持有的真题/课程素材加工成**可做题库 + 课程库**，
浏览器里做题 → 判分 → 错题本 → 统计，附 NAS Docker 部署管线。

> **本仓库只含代码。** 题库内容（`data/`）、素材加工产物（`build/`）、学习记录
> （`records/`）与文档账本（`docs/`）都在本地/NAS，不出库——真题与课程素材
> 有版权（ETS、课程方），不应公开发布。克隆本仓库得到的是可运行的空系统。

## 组成

| 部分 | 说明 |
|---|---|
| `server.mjs` | 零依赖 Node 服务：静态页 + 题库/课程 API + 媒体流（Range）+ 学习记录持久化 + 可选自签 TLS |
| `web/` | 单页应用（原生 JS/CSS，无构建）：做题跑道、视频课、错题本、数据分析；响应式布局 |
| `pipeline/` | 素材 ETL（Python）：解析 PDF/docx → 结构化题库 → 程序化校验（`verify_content.py`） |
| `deploy/` | NAS 部署管线：发布包 → Docker 镜像（内容快照）→ 健康断言；一键 `sync.sh` |

## 设计要点

- **内容与代码分离**：镜像 = 不可变内容快照，版本号即内容版本；学习记录是挂载卷，换版本不丢。
- **判分诚实**：缺官方答案的题如实「不判分」，不编造；官方答案键始终是判分唯一标准。
- **服务端唯一真源**：学习记录全量替换语义 + 客户端 resync，防旧标签页回传幽灵数据。
- **音频映射可核查**：逐题音频按文件名区间重映射，整段录音 >900s 时标注「整段 · 未分段」，
  无可靠切点的科目整体封锁为「暂不可练」（见 `deploy`/`pipeline` 内的校验脚本）。

## 跑起来（本地开发）

```bash
node server.mjs --port 8018     # 需要 data/ 与素材目录（本仓库不含，见上）
```

## 部署（NAS / Docker）

```bash
sh deploy/sync.sh               # 自动递增版本 → 打发布包 → sudo 部署 → 外部健康断言（约 30s）
sudo sh deploy/nas-rollback.sh <旧版本标签>
```

详见 [deploy/README.md](deploy/README.md)。
