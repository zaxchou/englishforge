# 词根宇宙：三个可操作场景

2026-11-06，使用 oil-ui-pro 的产品工作区/存量新增功能规范，沿用 TOEFL Lab 现有视觉。这里是可试走的效果演示，不是正式词典上线，也不代表后台工作包已经完成独立来源复核。

## 打开

在项目目录运行：

```sh
node prototypes/root-universe-demo/serve.cjs
```

默认仅监听127.0.0.1:4186，可用ROOT_DEMO_PORT环境变量改变端口。

- 查一个词：http://127.0.0.1:4186/?view=lookup
- 探索词族：http://127.0.0.1:4186/?view=graph
- 串联练习：http://127.0.0.1:4186/?view=practice

三个入口是一套界面的三个场景。没有使用生产API、付费接口、麦克风、账号或学习记录。搜索仅覆盖当前内嵌小词集；不匹配时明确显示未收录。练习选择与完成情况仅在当前页面内存，不写本地或服务端进度；刷新后重置。

## 可以试什么

1. 搜索unpredictable/predictable/prediction，查看构词、例句、同族词，展开出处。输入未收录词也能恢复到已有词。
2. 点predict词族的节点，查看右侧说明、以新词展开两层附近关系、返回上一词；切换photo-词族。现代构词和历史溯源分别标注；图中历史中间形式由连线和详情补充。
3. 完成predict词族三题，查看正确/错误反馈、下一题、完成和重练，也可随时回看图谱。练习例句为演示原创；结果不宣称整个词族已掌握。

## 数据和边界

内容依据及许可见DESIGN.md和页面出处面板，Wiktionary内容按CC BY-SA 4.0整理，中文为译文。内嵌小词集用来演示目标交互；正式索引仍必须按后台契约完成节点/事实/证据闭包的独立复核。本演示没有拿候选包的状态冒充正式批准。品牌图片复用当前项目T.资产。

这是三个互补功能的演示，不是三种视觉风格。后续是否采用此布局，应以用户实际试用反馈为准。未修改正在开发的root-universe模块和旧学习界面，未提交或部署。
