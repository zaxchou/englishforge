# 44 · 听力与口头回应链交付

2026-10-01｜Zcode｜基线 db16020 → 本批。对应 42 号（听力/口头回应训练链 + 路径解释）。

## 先说用户从哪里进、学到什么

**听力链《听出主张和限制：从一段汇报开始》（les-listening-c1，O-K184-01/O-K184-02 主课）**——42 号要求的六步全部落地，且是**真实规划器的主推荐**（不再是阅读备用顶听力缺口）：

1. **无稿首听**（l1a）：新情境"学习小组周会汇报（复习提醒）"——合成音频 34 秒（synthetic 如实标注），首听不显示脚本；听后三空选择：最后的决定？限制的条件？"每天提醒"被说成彻底没用了吗？未播放直接拒绝作答（服务端播放记录是听力证据前提）。
2. **提示/分段**：hints 引导抓结论句与转折词；音频可重复播放（=自行分段）。
3. **校对稿解释**（l1b）：脚本原文入题面（synthetic_exact，按构造成立），两空定位（限制句在哪、In fact 分开哪两件事）——记 **reading**，不冒充听力。
4. **关稿重听**（l1c）：校对稿收起，同一音频新问题（转折词是什么？平时周处理是关掉还是缩短？）。
5. **换材料再试**（l1d，transfer）：第二个新情境"宿舍洗衣时间表"（27 秒，4 段：做了什么/为何/何时有效/限制与决定），听后三空选择。
6. **口头回应**（l1e）：页内录音——"你接受『只在考试周开提醒』吗？立场 + 限制条件（as long as / unless）"。机器词表反馈=练习参考，口语掌握待人审（如实标注）。

**口头回应链《回应追问：把决定说清楚》（les-oral-c1，O-K190-01/O-K194-01 主课）**：新情境"项目站会改到周六上午"——脱稿讲清决定/原因/条件（三步式）→ **门控追问**（完成第一问才出现）："小周周六加班来不了怎么办？"——即时回应：给安排并说明不是取消他的参与。口述证据 defer：不给掌握正分（测试断言 0 observed 事件）。

**素材与许可（42 号"先用已持有且来源许可清楚的材料"）**：两段都是本项目原创受控脚本 + Windows SAPI 合成（Zira），manifest 带 sha256/时长/逐段意义依据/逐字转写；素材池登记 listen_synthetic + audited、限 O-K184-*。诚实缺口保持并写进素材标注：单一合成声源——**"换声音"做不到**（本机只有 Zira），换的是材料与情境；自然讲者录音待真人。

**synthetic 听力封顶 trained（兑现课程文案里写了但代码没落实的承诺）**：synthetic 音源的听力事件带 `syntheticAudio` 标记，状态回放对 listening 槽封顶「已练」——机器听后选择全对也不升 independent；升级留给自然讲者素材或人审结论。校对稿步骤的 reading 证据不受此限（读稿是真阅读）。

**路径解释（42-3）**：备用卡现在显示"它练的方向：〈行为名〉"（fallback 载荷带 objectiveIds，前端用 goalLabel 渲染）；主目标是听/说时额外提示"备用任务不能替代它——不会把阅读/写作结果记成听力掌握；听力主课在准备中（合成音频、证据受限）"。sound_segmentation 的等待文案从"W5 前无原声死等"更新为现状（合成音频课已上线、自然讲者待录）。fallback 理由固定含"主目标缺的能力不会被它补上，也不会被它记成掌握"。

## 过程中抓到并修掉的问题

1. **开放文本题不产生任何能力事件**（keywordOnly 跳过 observed）——第一版听力链全程零证据。听后任务改为**封闭槽位**（听后选择），产生带播放校验的真实听力事件；这也和"听后选择题"的评测效度一致。
2. **synthetic 听力封顶只在文案里、不在代码里**——补 `syntheticAudio` 基标 + 回放封顶，测试断言封顶生效。
3. 口述活动 conditionsSpec 与 oral 路由实发键不一致（CONDITIONS_INCOMPLETE 400）——对齐到既有 les_l3 形状。
4. 洗衣稿 3 段不满足清单测试的 ≥4 段结构——拆成标准四段（多了"为何这么做"的动因段，教学上更完整）。

## 如实保留的边界

- 单一合成声源（Zira）；"换声音再试"未达成，换的是材料与情境；自然讲者录音、真人听校、设备播放试听继续挂账（素材行如实标注 humanReviewed=false）。
- 听力证据封顶 trained 是**合同决定**（受控练习音频），不是效果结论；自然讲者版本的升级路径需要真人录制+听校。
- 口述任务在真录音链路里证据 defer，掌握待人审；转写词错≠你的错照旧。
- 默认模型判定质量、真人签署、全图核验：挂账不变。未授权付费调用未发生；调度暂停。
