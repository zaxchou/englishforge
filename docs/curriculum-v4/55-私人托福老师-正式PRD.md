# 55 · 私人托福老师正式产品需求文档
版本 1.0｜2026-10-02｜产品流程基线，待本人原型验收后冻结视觉及实施合同

## 1. 产品结论与规划复核
做一个面向本人、在NAS使用的托福学习系统：以可追溯原题为练习基础，以教师课程提供有组织的方法，以AI私人老师提供针对实际作答的解释、补练和后续安排。衡量价值的是新题上的独立表现与正式考试成绩，不是题数、观看时长或AI生成量。

53/54的主线成立，但还有五处不能直接交给开发：首次基线不清楚；“会了”阈值未定；四科只有文字流程；材料音频与答案尚未全部配对；AI反馈质量未通过真实验收。本文件把产品行为和验收写清，技术供应商及评分校准留为显式关口，不用假数据填补。
用户此次授权PRD与demo；没有授权正式托福业务开发、部署、恢复定时任务或额外付费。

## 2. 用户、目标与范围
个人情况来自自述：四级基础，词汇约8000–10000，基础语法需重整，声音识别和意义调用慢，长句关系不稳，口语以模仿为主，主动表达较弱；每天3–4小时，至少一年后考试。目标分和具体日期尚未确定，界面允许“尚未确定”，不预设100分或某档。

P0必须支持四科完整学习闭环、课程资源与个人记录。目标最终覆盖当前12类任务，首批可分期上线但明确缺口。不是英语知识图浏览器，不是计时入口，不是AI大量出题器。
不做多人运营、商业分发、支付系统、自动代写提交、模拟官方自适应算法；不把旧题型整套冒充当前考试。
张俊杰21课与72单元地图为后台解释语言组织的参考，新东方讲义为专项方法参考，原题和原音检验运用；不将某一老师口诀当普遍语言规则。

## 3. 可验证的成功标准
1. 首次进入，用户在30秒内能说清今天做什么、为什么做、完成后会发生什么。
2. 首次作答、提示后作答、看答案后重做、未见题检查严格分开。
3. 每次复盘有原文/原音或本人片段作为依据，有一个优先改进点和可执行下一步。
4. 连续学习不会反复返回同一道已做题；题库不足如实显示，不改选项顺序冒充新题。
5. 用户能看到自己的第一稿/原音和后稿/重录，并理解哪些进步还需新题验证。
6. NAS刷新、切设备不丢作答或课程位置，AI失败仍能继续或稍后分析。
这些是产品验收指标，学习效果需数周真实使用和正式成绩验证，不承诺固定提分幅度。

## 4. 信息架构
一级导航：今天、练习、课程、进步、计划。AI老师绑定当前任务，在提交后出现，不是独立万能聊天首页。
- 今天：一个主任务、推荐理由、预期出口和继续入口；可换科目/自选。
- 练习：按科目/12类任务/套卷组织，来源、已见状态、模式清楚；保留套卷关联。
- 课程：新东方教师章节、讲义、续播、笔记及看后原题；相关片段在复盘中链接。
- 进步：独立表现、帮助依赖、任务覆盖、作品变化及仍不确定的判断。
- 计划：近期重点与一年以上阶段路径，可调、可免修，不强制每天四科深练。
移动端：首做主材料优先；老师复盘单独页签，切换保留输入；底部导航不遮编辑器。

## 5. 首次进入与诊断
收集目标分/考试时间（可跳过）、已经练过的材料、可用时间；已有自述可预填但让本人改。先介绍当前题型，基线分几天完成，避免一次四科过载。
首项默认本人选择科目或系统给“熟悉任务”推荐。无数据不得显示“你最弱听力”。
首次基线四科均需至少一组独立产物，逐步补充任务覆盖。不是几题即可精确估分；开放题只提供辅助反馈，不显示伪官方总分。
做过或看过同题讲评，标为已接触。可学习但不进入未见基线。本人申报熟悉可以跳过；“自评熟悉”与新题表现分开。
目标分未定不阻止学，但不计算到目标差多少；考试版本、评分档位和单项要求在设定目标时核对。

## 6. 统一学习合同与状态机
状态：未开始 → 首做中 → 已保存待复盘 → 老师分析中 → 复盘 → 补练/重试 → 待新题验证 → 已验证/需继续。
分析失败分支返回已保存待复盘，显示稍后重试和查看核验解析；不会重新提交生成重复Attempt。
每日可以停在任何保存点。未达标不无限锁关，可结束、换练法、先学方法或降低支持撤除速度。

首次任务页显示：题目主题与类型、为什么安排、预计时间（估计）、独立/精学或限时模式、材料来源。首做默认无老师解析，不自动显示答案/稿。
学习模式允许主动查词/求助/重复播放，记录支持条件；需要时确认结束独立首做后进入帮助，不能悄悄继续算独立。
限时检查不提供提示、翻译、稿、自动补全；到时保存当前输入，答题提交后复盘。
整组提交后答案不再改写；后续重试新建关联版本，旧记录可看。
每次老师最多主动推一到两个改进点；“直接看完整解析”与“先给提示”都可选。
进入下一道验证题时必须说明区别与选择理由，不保证安排的题难度已校准。

## 7. 分科需求和12类任务
| 科目/任务 | 首做 | 复盘/补练 | 验证出口 |
|---|---|---|---|
| 阅读：补全单词 | 原文原空位输入 | 词形、搭配、语法和上下文线索 | 新段落同类线索 |
| 阅读：日常文本 | 通知/邮件原版式及题组 | 定位对象、时间、条件；证据对照 | 新文本独立定位 |
| 阅读：学术篇章 | 全文与相关问题 | 按需主干/修饰、词义、推断、段落功能 | 新篇章理解与用时 |
| 听力：选回应 | 原声一次播放与选项 | 请求/问题/态度和恰当回应 | 新原声回应 |
| 听力：对话 | 无稿听完做题组 | 声音、意思、话轮意图分支 | 新对话首听 |
| 听力：公告 | 无稿抓行动信息 | 目的、变化、要求 | 新公告关键信息 |
| 听力：学术谈话 | 听整体、可做笔记 | 概念/例子/关系保持，短信息重建 | 新谈话整体理解 |
| 口语：听后重复 | 原句后录音、无稿 | 内容准确性和可懂度分开，原声意群补练 | 新句完整重复 |
| 口语：采访 | 听原问独立回答 | 回应、具体细节、组织、可懂度；优先一点 | 新问题无稿回答 |
| 写作：组句 | 原槽位/词块/干扰词 | 主线、嵌套、搭配与语境限制 | 新题组句 |
| 写作：邮件 | 完整第一稿 | 对象、目的、要求、清楚请求；本人修改 | 新交际任务第一稿 |
| 写作：学术讨论 | 独立短文回应讨论 | 扣题、贡献、理由支撑，组织语言 | 新讨论独立回应 |

阅读选中句子打开教学标注，不改原文；高亮证据可保存。长句拆解不能替代整篇理解。
听力看稿后立刻懂可支持听辨困难假设；看稿仍不懂可支持词义/结构困难假设。学生可不同意；一次错误不确诊。首听和重听分别记录；听写不是每段必经。
听后重复不把同义替换算准确重复；采访允许换表达，不规定万能四段模板。ASR仅辅助，不以转写逐字正确率代替可懂度。
写作第一稿、学生修改、AI建议分别归属；AI代写不记为本人掌握。系统不把字数增加当提分。

## 8. 私人老师合同
输入：锁定的task/content版本、原文/匹配稿、核验答案与来源、原始作答、支持事件、本人疑问。只发送必要内容，模型在云端与NAS本地部署分别说明。
输出结构：本次观察、证据引用、错因假设及置信说明、区分假设的一个问题、优先教学点、提示梯度、完整解释、补练动作、后续推荐理由。
引用需要绑定原文范围/音频时间或本人片段；没有已核对时间戳时不能生成精确跳播点。题面不可答、解析冲突或证据不足时停止确认答案并保留疑点。
封闭题按核验答案判；模型不同意不能自动改官方/核验答案。开放题反馈标为辅助，有异议可指出、重新分析；不提供未经校准的总分。
模型超时/无效输出/转写不可靠：保留作答、显状态、不更改掌握。不同task上下文隔离，避免串题。
教学解释可以生成；核心题与验证题默认原题。额外AI练习是否允许仍待本人确认，不能偷偷上线为真题。

## 9. 适应性安排与成长
分别保存“观察”“老师假设”“本人确认”“新题验证”。展示状态：暂无依据、提示后能做、独立表现有支持、还需检查；不向学生展示锚点ID。
V1策略：有错因线索时优先一项补弱；否则扩展未覆盖任务。预设最少不同题组、跨日无提示观察作为可配置阈值，尚未校准，不称认证。
同题重试不增加独立样本量；已见题不进保留池；不因一次新题错误清空历史。
推荐可替换、可拒绝、可免修，记录理由；不给选择当错误。学习计划只调未来任务，历史与已提交内容保持原版本。
一周重点给两项以内，计划结合现有词汇/chunks习惯，不挤掉全部外部学习。默认一个深度主练、一个短输出，其余按本人时间调整。
阶段：任务熟悉与基线 → 方法和语言基础修复 → 专项限时与不同话题 → 模考节奏与考前补弱。不是固定日历升级。
“进步”显示新题准确/用时/辅助条件和作品对比，样本数与题型范围可展开；无基线时为空态，不生成漂亮雷达图。

## 10. 教师课程与媒体管理
章节可自主学习，也可由当前卡点推荐；只配到已经核验的讲义页/视频章节，不凭标题生成精确时间戳。
保存：stableMediaId、最后位置、速度、实际观看区间合并、最后时间、笔记及PDF页、完成/免修申报。拖到末尾不算全看；重复同区间不增加覆盖。
“课程已看/自报完成”与“新题运用”两条记录，不能同步认证。
NAS媒体HTTP接口支持Range，读取限定教材目录，禁止任意客户端路径，ID改路径保留进度。不暴露整盘。
抽样校验各科视频容器/编码及目标浏览器，需时先MP4重封装，不兼容再按需转码，原文件保留。未下载完/损坏/缺音频显示原因和替代讲义入口。
记录写NAS而非仅localStorage；自动保存断线提示和恢复，备份能恢复媒体映射、作答与笔记。云AI默认不传整个视频。

## 11. 原题内容入库合同
流水线：发现文件 → 哈希去重 → 分类来源和考试版本 → OCR/抽取 → 原页校对 → 音频/稿/答案配对 → 题组审核 → 可学习或暂存。
必须有sourceAssetHash、套卷/module/task/题号、PDF页序、选项/槽位、答案来源、解析来源、音频范围、内容签名、审核状态。
哈希同不重复入库；同题不同排版归一组资产。文件计数不能显示为题数。学生版与教师版第1套不是同卷，不能按名称配对。
来源状态：已核验官方练习、第三方练习、回忆整理、待核实。目录名“真题”不是认证。纸面适配不宣称精确模拟官方自适应考试。
答案/解析/完整稿不在首次答题API下发。没有答案可精学开放理解，但不能封闭判分；缺音频不得转成已完成听力。
保留池由明确未见材料组成，曝光含看解析/老师讲同题/课程讲评；题库不足可补资料或扩大类别，不编新题填充。

## 12. 概念数据及接口责任
产品实体：LearnerGoal、SourceAsset、ContentVersion、TestPack、TaskGroup、Question、AnswerKey、TranscriptSegment、CourseChapter、LessonLink、Attempt、SupportEvent、Feedback、Hypothesis、PracticeVersion、Verification、PlanRevision、ViewingInterval、Note。
Attempt绑定contentVersion、mode、起止时间、首次/重试关系、答案/录音、支持标记；提交使用幂等键，重复请求返回同记录。
Feedback绑定输入版本与模型配置；新解释不覆盖旧反馈；老师补练和下一题为不同事件。
拟定服务边界（路径为实施提案）：GET /tasks/:id public首做内容；POST /attempts保存/提交；GET /attempts/:id/feedback；POST /feedback-jobs；POST /plans/recommendations；GET /media/:id Range；PUT /courses/:id/progress；POST /notes。
提交成功以服务器持久化为准，分析异步，失败可恢复。未批准前不冻结框架/数据库/供应商。生产鉴权至少保证只有本人访问，密钥不放客户端。

## 13. 状态与可访问性验收
| 场景 | 必须发生 |
|---|---|
| 空基线 | 显示熟悉/起步任务，不显示分数和虚构弱项 |
| 缺材料 | 指出缺音频/答案/稿，提供可用部分；不生成假成功 |
| AI失败 | 作答保留，可稍后分析/看解析 |
| 输入无效/空录音 | 就地说明，保留其他输入，不进入已完成 |
| 浏览器无麦克风权限 | 提示允许权限或导入录音；不出现假波形假转写 |
| 刷新/断线 | 草稿恢复，提交幂等，清楚已保存还是仅待同步 |
| 切科目/看课 | 先存当前位置，返回同题同稿 |
| 限时到 | 保存当前答案并结束首做，之后复盘 |
| 推荐无新题 | 显示待补充，可自选课程，不伪装已验证 |

正文桌面至少16px，移动优先18px上下文正文，英文长文舒适行长；对比度按WCAG AA目标。所有按钮可键盘操作，焦点可见，录音状态不能仅靠颜色。缩放200%不遮主动作。长文和老师不互相覆盖，错误/等待/成功都有文字说明。动效克制且尊重减少动态效果。

## 14. 实施顺序与关口
| 批次 | 交付 | 验收关口 |
|---|---|---|
| P1 原型（本轮） | 两种布局同内容；四科闭环、课程、进步；PRD与说明 | 本人能理解并完成流程；选择/修订体验 |
| P2 内容和技术试验 | 一套原题/稿/答案校对；12类任务至少样本；真实AI/ASR反馈评审；NAS媒体抽样 | 不串题、不伪分、有依据；成本与数据边界清楚 |
| P3 首个可用版本 | 四科各一条完整闭环、作答和课程持久化、失败恢复 | 本人真实试学一周，新题验证可用 |
| P4 全任务与库存 | 12类任务、保留池、套卷检查、来源管理 | 材料覆盖/曝光统计准确，各科交互独立验收 |
| P5 长期个性化 | 多周数据修订计划、建议质量回看、外部分数录入 | 学习进步与误诊可追踪，不止增加题数 |

P2之前本人决定目标分、已练过材料和额外AI补练政策；供应商选型/预算/评分校准实验需要明确方案，不由开发猜。尚无这些条件不妨碍P1。
本文件为正式产品需求基线，视觉方向及用户试学未确认部分不能写成已验收。正式业务开发启动另作确认；本轮不交接Zcode。
