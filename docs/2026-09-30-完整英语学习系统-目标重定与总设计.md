# 完整英语学习系统：目标重定与总设计

日期：2026-09-30  
状态：产品与课程总设计建议；不包含代码实施。  
依据：用户本轮明确要求、项目原始计划与 v2/v3 计划、21 份校对课稿的目录和部分原文、当前课程组织与实际学习记录。  
核验边界：已确认素材共 3 份先导片和 18 份正课；本轮未完成全部课稿的逐段知识提取，也未完成参考语法书的逐条覆盖核验。下述知识版图是待核验的总设计，不能宣称已覆盖所有英语语法或已形成完整课程。

## 1. 用户已经明确的产品目标

以下是用户要求，不是待选择的缩减方案：

1. 把张俊杰的 21 份课程素材作为一个整体，提取组织英语知识的逻辑，并向外延展。
2. 建立从基础到高级、可持续推进的完整英语学习系统。语法知识的完整覆盖是明确目标。
3. 用户有一些英语基础，希望重新按逻辑建立体系，获得实际理解和使用能力。
4. 保留通过一步一步做题推进的体验；练习必须逐步增加能力和组合复杂度，避免换题面重复同一简单判断。
5. 产品应具有自己的教学组织方式，不能止步于视频配套题或几百道练习的 demo。
6. 先规划课程系统，暂不修改代码。

原计划中的轻操作、允许语音、语法优先、每日短时学习等偏好继续保留。完整系统的目标优先于 v2/v3 中被过度延长的局部样板范围。旧文档保留为历史，不直接删除或覆盖。

## 2. 产品定位

面向有基础但知识零散的成人，以“想表达什么 → 选择什么结构 → 为什么这样表达 → 在新场景中使用”为主线，组织从基础到高级的英语课程。

课程要同时交付三种结果：

- 系统理解：知道不同语法结构在解决什么表达问题，以及它们如何联系。
- 使用能力：能够理解、构造、转换和组合表达，逐步降低对选项和提示的依赖。
- 持续推进：清楚当前位置、已达成的能力、下一段目标和课程剩余范围。

语法是主干。声音、词汇、搭配、听读输入和说写输出与主干衔接，避免语法题做完却无法理解实际材料。语法课程完成度与整体听说读写能力分别展示，不能互相冒充。

## 3. 三套组织方式，各自解决一个问题

### 3.1 知识目录：检查完整性

从有明确版本的综合语法参考资料和分级教学资料提取条目，建立稳定的知识清单。每条要能追溯出处，并标记已覆盖、部分覆盖、尚未覆盖和争议待核验。

“所有”落实为可检查的完整覆盖要求：选定参考范围中的每个条目都必须有去向，不能因为原视频没讲、暂时不好出题或属于高级内容就消失。

常用、低频、正式、口语、变体等属于学习优先级和使用范围标签；低频内容仍进入目录及高级分支。资料扩展后记录新增条目，不以一个永不变化的题目总数定义英语的边界。

### 3.2 解释框架：形成产品特色

从整套课稿中提炼含义与形式、词的作用、句子组织、时间与状态、叙述焦点、语气和简化等解释线索，贯穿不同知识领域。

每条解释区分三种来源：原课明确讲述、依据原课思路进行的产品推导、补足原课覆盖范围的参考资料内容。产品延展不冒充张俊杰原话。

教学比喻要有适用范围。涉及事实性或绝对化表述时，核对语法与词典资料；保留有帮助的理解方式，修正会误导造句或判题的概括。不能为了统一口号而把合理英语判成错误。

### 3.3 学习依赖：决定先学什么

知识目录不是学习顺序，视频编号也不直接决定关卡顺序。

每个学习目标需要标明硬前置、可同时学习的背景知识、后续组合目标。前置关系应无循环；不同领域可以交叉推进。同一大主题分基础、进阶和综合节点，不能要求学完所有时态才能首次接触被动语态等基础组合。

成人路线依据能力定位进入相应节点。会选择但不会表达、会阅读但听不清、基础形式会用但复杂语境不稳，要进入不同补足路径。

## 4. 全范围知识版图草案

下表用于启动覆盖工程。它不是已完成的原子知识清单，也不能据此宣布“全部覆盖”。后续必须细化到有来源、边界、前置和检测任务的条目。

| 领域 | 必须展开的范围 | 与全课程的联系 |
|---|---|---|
| 声音与书写 | 音素、音节、重音、常见拼写对应、词尾读音、弱读连读、语调、标点与大小写 | 支持听辨、词形感知与表达；成人可按缺口进入 |
| 词汇与构词 | 词根词缀、派生与复合、词族、词义与语境、搭配、固定表达、短语动词 | 与语法节点同步提供受控词汇，避免生词掩盖语法能力 |
| 词类与短语 | 词类、词类转换、短语中心与修饰、词类和句子成分的区别 | 把单词组织成可以进入句子的单位 |
| 名词系统 | 可数与不可数、单复数、集合名词、专有名词、数量表达、所有关系 | 名词短语、限定和一致关系的基础 |
| 限定与指代 | 冠词、零冠词、指示、数量词、物主、人称、反身、相互、不定代词及指代衔接 | 说明谈论哪个对象、多少对象及上下文中的指向 |
| 描述与比较 | 形容词、副词、位置与修饰范围、程度、比较级最高级、比较结构 | 从简单描述走向精准表达及歧义处理 |
| 关系表达 | 介词和介词短语、时间空间关系、抽象关系、介词搭配、介词与小品词 | 连接对象、动作和情境，兼顾组合规则与具体用法 |
| 动词与补足 | 动词形式、实义与系动词、助动词、及物性、配价、宾语与补语、动词搭配 | 组织句子骨架，连接后续时体与非谓语结构 |
| 基础句法 | 主谓、主系表、宾语和补语、状语、主谓一致、there 与形式 it、词序 | 形成可独立使用的基本句 |
| 句式与极性 | 陈述、疑问、否定、祈使、感叹、特殊疑问、附加疑问、简短回应与否定范围 | 让表达可以询问、回应、否认和要求 |
| 时间与体 | 现在过去、进行与完成、完成进行、将来表达、时间参照与时间状语、叙述时序 | 表达事件时间及观察事件的方式；不限于机械填写时态表 |
| 情态与语气 | 能力、许可、义务、必要、可能、推断、意愿、礼貌、情态完成结构 | 说明说话者态度和判断强度 |
| 语态与参与者 | 主动被动、不同时间/体/情态组合、施事省略、get 被动、使役及相关结构 | 在同一事件中选择叙述焦点，并处理动词使用限制 |
| 非谓语与补语从句 | to 不定式、动词 ing、过去分词、动词/形容词/名词后的补足、非谓语主语及时间语态、意义差异 | 把动作作为内容、补足或修饰；处理复杂组合 |
| 并列与从属 | 并列结构、关系从句、内容从句、嵌入疑问、时间原因目的结果让步等状语从句、简化从句 | 把多个命题组织成清晰关系 |
| 条件与非现实 | 事实条件、预测、假设、反事实、混合时间、wish/if only 等表达 | 联合时间、情态和从句表达不同现实程度 |
| 转述与视角 | 直接间接引语、陈述/疑问/要求转述、时态与指示变化、转述动词 | 随说话者、时间和场景改变表达视角 |
| 信息结构与衔接 | 主题与焦点、强调、倒装、分裂句、前置与后置、省略、替代、指代、连接与段落关系 | 从句子正确走向篇章清晰和自然 |
| 使用范围与复杂边界 | 口语与书面、正式与非正式、主要标准变体、习惯结构、复杂一致与修饰、歧义和编辑 | 为高级与低频条目提供明确归属，避免漏项 |
| 综合理解与表达 | 对话、叙事、描述、解释、比较、论证、改写与编辑 | 综合调用知识，独立检验听读和说写表现 |

单个知识点可能涉及多个领域，只维护一个主条目并建立关联，避免同一知识反复建关、重复计算进度。

## 6. 从 0 到 100 的全程能力路线

这里的 0～100 是完整课程路线的里程碑标记，不是英语水平百分比，也不意味着 100 即掌握所有词汇、文化和场景。下列位置是规划区间，实际进度权重要等知识清单和任务完成后确定。

| 路线位置 | 阶段能力 | 典型成果 |
|---|---|---|
| 0～10 | 补足必要声音/词汇入口，建立词、短语和句子的关系 | 能理解任务要求，区分谈论对象、动作与描述 |
| 10～25 | 组织基本句，限定对象，提问和否定 | 介绍人和物、描述状态、询问信息，并表达简单关系 |
| 25～40 | 表达时间、过程、完成与计划 | 围绕同一情境表达习惯、发生中的事、经历及安排 |
| 40～55 | 表达态度、改变焦点，组合已有结构 | 提出请求、建议和推断；按需要选择主动或被动 |
| 55～70 | 扩展名词短语与句子，组织多个动作和命题 | 使用非谓语、并列及从句说明目的、原因和对象特征 |
| 70～85 | 处理假设、转述、复杂时间与视角关系 | 讨论不同可能性、转述消息、解释复杂事件 |
| 85～100 | 整合高级结构、信息组织和使用范围 | 在较完整的材料中理解、表达、改写、消歧和编辑 |

这是螺旋推进：早期引入简单比较、条件或连接，后期处理复杂用法。不能把某个领域整体封锁到后期；每个具体节点由前置关系决定位置。

声音与词汇支撑贯穿全程，综合任务随阶段发展。低频和专门用法纳入有位置的分支与参考区，并标明课程完成要求；不可以隐藏未覆盖内容来凑“100”。

## 7. 特色如何体现在实际学习中

采用“同一表达意图逐步生长”的课程组织方式，并在检测中更换场景，避免熟悉故事造成虚假掌握。

例如围绕“介绍一份工作并解释为什么选择它”：

- 起步能说谁在哪里工作，区分人、动作与地点。
- 随后能描述日常安排，并提出问题和作出否定。
- 再能对比过去和现在、解释经历与计划。
- 加入理由、条件、相对评价和别人转述的信息。
- 最后能组织一段表达，依听众和场合调整重点与语气。

每次增加一种有用途的表达能力。难度来自信息关系、独立程度和知识组合，不靠突然塞入大量生词或单纯加长句子。

每个目标都安排理解与使用，但不强制所有目标经过同样六档。选择题、关系判断、局部修改、词块组合、短答、口头表达、短材料理解分别服务于具体目标。轻点击是主要交互偏好，必要的独立产出可以用简短输入或语音完成；没有可靠评价时明确记录为待验证，不冒充掌握。

## 8. 从知识到教程、题库和关卡

完整链条：知识清单 → 前置关系 → 阶段能力 → 学习单元 → 教学任务 → 练习与检测 → 用户证据 → 下一步。

每个知识节点至少包含：

- 稳定 ID、所在领域、表达功能、范围及边界。
- 课稿位置、参考资料条目、原课/延展标记。
- 硬前置、软前置、关联与后续组合目标。
- 常见混淆、必要词汇、受控语境、提示方案。
- 解释、正反对比、针对性反馈和可接受表达。
- 练习、独立检测、延迟检查各自需要覆盖的条件。
- 从基础识别到实际使用的适用难度层，以及过关证据。

题库规模由这些覆盖需求推导。先给出每个节点要检验哪些对比、语境和组合，再决定需要多少任务；不先拍脑袋定 300、1500 或 10000 道。

每道题必须有教学用途。只换人名或名词的变式不能作为新增能力节点，不能增加课程进展；它们可以有限用于熟练化和复习。

## 9. 内容怎样持续生长

可以自动化的生产流程：

1. 从目标节点与覆盖缺口形成任务规格。
2. 按已审核的语法范围、词汇范围和难度约束生成教程与任务候选。
3. 检查英语准确性、自然度、语境充分性、答案/替代表达、解析及知识归属。
4. 检查是否引入未学结构、是否与既有任务过度同质、是否泄露检测材料。
5. 由独立审查与结构检查形成可追溯结果；未通过的候选不进入正式路径。
6. 以完整学习单元发布，记录版本、前置和后续单元，并观察实际使用表现。

生成器服务于课程规格。不能让模型无目标地“再出 100 道语法题”，也不能靠在线临时生成来保证下一关一定存在。已发布阶段需要有足够的完整内容储备。

不要求用户逐题充当编辑。系统负责维护内容；对尚无可靠判定的开放表达保留不确定状态，不给虚假的能力结论。

## 10. 成人路线、推进和复习

- 原有作答记录作为定位线索，不直接把答对基础选择题当作高级能力证明。
- 分领域、分层次进行短诊断；能够独立完成目标任务就进入后续节点，不要求刷完题库。
- “具备进入下一步的能力”和“长期保持稳定”分别记录。可以继续学新内容，同时安排旧知识的延迟检查。
- 一个目标过关后，不因为剩余题目很多而继续占据主线。
- 错误引导到具体前置或混淆点，补足后回到原路线；不因一次错误将整章重置。
- 学习页说明当前在完整路径的位置、本关能力增量、下一关是什么。
- 正常推进轮次以课程目标为主，复习比例可调整；纯复习有明确身份，不能包装成新课。

成人的不同领域可能处于不同层级，不能强制用一个总分决定所有内容的难度。

## 11. 如何验收“完整”与“有效”

### 完整性验收

- 21 份素材全部有提取与归属记录。
- 选定参考目录中的条目全部进入覆盖矩阵；未覆盖、部分覆盖和高级分支公开可查。
- 每个正式路径节点都能追溯到知识目标；每个目标都有教程、练习和适当检测。
- 前置关系无循环、无无法进入的孤立节点；高级目标具有可走通的前置路径。
- 完整路线有阶段结束条件、下一阶段内容和总完成条件。
- “设计完成”“内容可用”“已经发布”“用户已掌握”分别统计。

### 递进与效果验收

- 同一学习者连续多次使用，任务要求与可完成能力有可解释的变化。
- 已会内容能够跳过或快速通过，不靠固定作答次数换取解锁。
- 陌生检测材料不提前出现在教学和普通练习中；重复材料不算首次迁移。
- 能记录理解、受控构造、独立表达和延迟保持的不同证据。
- 在不同领域和不同阶段检查学习体验，不能只验证主宾格一个局部就推广到所有课程。

认知效果需要真实试用，不能仅靠软件测试确认。局部试用用来校正完整设计和内容，不改变产品的全范围目标。

## 16. 复杂句理解：解释依据与训练设计候选

本节是设计依据与建议，未完成训练效果验证，不作为用户已确认的具体方案。

- 研究支持语言理解会随输入逐步进行，语境可在早期参与词语和结构解释；不能描述成母语者先收齐整句、画完语法树才理解。[Tanenhaus 等，1995](https://www.csun.edu/~tab2595/TanenhausIVLISLC.pdf)
- 句子难度与结构依赖和暂存需求有关，多重中心嵌套可以造成理解负担；不能说母语者对任意长句都能瞬间理解，也不能仅按单词数或从句数标难度。[Gibson，1998](https://pubmed.ncbi.nlm.nih.gov/9775516/)
- 教学例子建议从已知词汇的基本关系开始，逐步添加修饰、内容从句、条件/时间关系及嵌套；帮助学习者识别新信息连接到哪里、何时回到暂未完成的关系。例子中的有意识分析是教学辅助，不冒充实际大脑逐步执行的算法。
- 训练候选：文字关系理解与意义检查 → 沿输入顺序分段理解 → 分段音频及完整音频 → 陌生材料独立理解 → 回答/复述/表达。先确认理解，再逐渐减少停顿和提示，不直接靠压缩作答时间提难度。
- 区分依次展开与层层插入的结构复杂度，分别安排任务；使用真实自然材料，避免以罕见且刻意拗口的多重嵌套作为流利度唯一标准。
- 同一材料反复听熟与陌生材料的理解分开记录。渐进训练也应跨主语、宾语、补语、关系修饰、状语、非谓语与信息结构等领域展开，不固定只扩展一种主谓宾句型。
