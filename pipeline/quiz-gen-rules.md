## 1. 先确定这道题在做什么

每题必须声明 `objective`（唯一主要考点）、`mode`（guided/retrieval/transfer）与 `testedItems`。

- guided：讲解后的引导例题，可给词根含义、词义提示；明确标“带提示练习”，不可计入独立掌握/无提示正确率。
- retrieval：独立提取。题干不重复待考结论；例如问 dome 的词义时，不先写“dome 是圆屋顶”。
- transfer：新例句里的运用。给必要语境，不给目标答案；词形、搭配、语义都必须成立。
- 填空测词义时，不先命名应填单词。若明确测 should 后的动词形式，可给 base form，但只测该语法点，不声称检测了词义。
- 同一概念不是不能复习，而是必须改变被考能力或明确为复习；换措辞重复同一结论不算新覆盖。

事故：01/q11、q12、q23、q24 直接泄释义；07/q10、q11 用样例词自己作答案；01/q9 是需要保留的例外：若测情态动词后原形，给 husband 不等于已给完词形判定。

## 3. 命题铁律（prompt 与人工/模型审核都执行）

1. **题干只给必要条件**。释义题不先给释义；同词比较不以该词自己为正确项；填空前后、括号中文、标题、提示、标签都纳入泄题检查。
2. **只有一个选项成立**。逐项把 A-D 代回完整句子，分别检查语法/语义/搭配/上下文。不能因正确项“更贴切”就把同样合理的另一项判错。
3. **判错理由是语言或任务条件**。禁用“本节没讲、老师没说、不是课堂给的、重点不在此、覆盖更完整”替代语义判断。只考课堂原句还原时，明确标注该任务，不能声称自然表达只有那一种。
4. **参考答案不能修补题干缺失条件**。例如题干没说“放在 5 和 2 之间”，解析不能临时加该条件排除 subtraction。
5. **填回正确答案后必须得到完整自然句子**。to mollifying、a matriarchy society、crust of the earth’s crust、heavy forecast will arrive 必须退回重写；不能只核对选项单词意思。
6. **题干问什么，选项就答什么**。问音变片段不拿完整单词作答案；问单词不拿后缀作答案；问“含 lig”不能用只含 lect 的同源词糊弄。
7. **目标词必须可见且唯一**。词义题直接给 `target` 字段或明确引号标示；不允许问“划线词”却既不划线也不给词，不能把词义题的目标挖成空。
8. **每项 note 与 explain 相互一致**。不得出现“这个也正确，但 A 更好”；不得把其他选项编号/解释串到当前项；不得用错误常识逼出唯一答案。
9. **干扰项可以稿外，正确考点必须有来源**。但有来源不证明语言事实正确，更不能仅凭任意一个英文词/四字符前缀重合就通过。
10. 本功能明确为“AI 课后练”，不是官方真题。原文引用与新造例句分别标注，不把改写句称为老师/考试原话。

真实反例：02/q13 anthropologist/archeologist；02/q23 avalanche/blizzard；06/q15 income/immigrate；06/q16 两种内政部长表达；15/q9 by no means/in no way；24/q4 concise/precise；33/q21 flower/effloresce。详见逐题处理。

## 4. 作答界面与统计边界

- 作答前只显示进度、题型和必要题面。**tags、testedItems、covers、词表高亮、完整解析在提交后显示**。可保留不泄题的科目标签。
- 不只藏标签内的正确词：词根/词缀提示也可能只指向一个候选；统一把考点标签移到答后。
- 提示由学习者主动打开，标记 assisted；有提示答对不记录为无提示掌握。
- 作答前隐藏答案是 UI 体验要求；若以后提供测评可信性，还需服务端判题，而不只 CSS 隐藏。
- 347/1203 题的标签等于正确项，另 18 题标签包含完整正确项。当前 `web/index.html` 的 `gq-prog` 在作答前拼 tags，必须改。

## 5. 格式闸门与后处理

| 闸门 | 合同与现有差距 |
| --- | --- |
| 四项与答案 | 必须恰好 A/B/C/D，所有文本和 note 非空，answer 精确为单字母。禁止先取第一个字符，也禁止截掉第五项后继续。 |
| 标签映射 | 按原标签取值，不能按 Object.entries 的返回顺序重标 ABCD 而 answer 不变。输入键乱序仍需保持 B 指向原 B。 |
| 重复选项 | Unicode NFKC + 大小写 + 空白归一化后去重；近义选项还需语义审查，不假装字符串不同就唯一。 |
| 去重 | 初始批、收尾补漏、extra、最终截断后都走同一个入口；按主考点+任务+语境判断近重复。重复例句合并时保留一个已有题，不重编号。 |
| 截断与覆盖 | 60 题上限可以保留，但**先截断，后从全部 taughtItems 重新对账**；不能只过滤截断前 remaining。 |
| 洗牌 | 保留按稳定题版本 seeded shuffle；选项对象与 note 同移，答案引用相应迁移。洗牌前后语义指向必须相同。 |
| 失败处理 | 单批可重试一次；失败部分标为未完成。有效题不足可发布少量已审题，不为凑四题放宽质量。 |

## 6. 覆盖、分级与版本

- `testedItems` = 做对这道题必须用到的知识点，有 objective + 答案判据支持。
- `mentionedItems` = 只在干扰项、note、explain、tags 中出现；不计已测。不能用 JSON.stringify 子串对账。
- 一个词仅出现在错误项解释，不表示学生被考过这个词；更不表示学生掌握了它。
- core = 本课实质教过且验证有证据；ext = 验证正确的拓展。未知 = pending，不能冒充 core/ext。
- 删除题/调换数组位置只要 id 不变，不应改已有身份；**重新生成不得把另一道题复用旧 qN**。新增内容版本号/内容签名，保留旧版本作答和错题回放。
- 坏题造成的错误记录标 invalidated，保留原作答但不继续计入薄弱点/SRS；不清空整节全部记录、不把坏题改正确来假装成绩提升。

事故：33/q40 covers 列出多个未实际考察的词且漏 crust；现 `covNow/gqInvChips` 用全 JSON 统计；现两处 finish/赋 id 均重用 q1...。本轮不改生产记录。

## 7. 发布状态与语义审核合同

链路：候选语言点 → 源段核验 → 候选题 → 机械检查 → 语义审核 → approved / rejected / pending → 版本化入库。

语义审核是下一步需实现的能力，本轮没有调用任何远程模型。不能把离线扫描器命中/未命中作为语义通过。

审核输入必须含实际题面、全部四项、全部解析、目标考点和证据。审核输出至少包含：

```json
{
  "questionSignature": "sha256-of-content",
  "sourceSignature": "sha256-of-source-segment",
  "ruleVersion": "quiz-rules-v3",
  "reviewerKind": "model-assisted-or-human",
  "decision": "approved|rejected|pending",
  "possibleAnswers": ["B"],
  "perOption": {
    "A": {"grammatical": true, "fitsContext": false, "reason": "真实理由"},
    "B": {"grammatical": true, "fitsContext": true, "reason": "题干证据"},
    "C": {"grammatical": true, "fitsContext": false, "reason": "真实理由"},
    "D": {"grammatical": false, "fitsContext": false, "reason": "具体语法约束"}
  },
  "answerLeak": false,
  "sourceAndFactVerified": true,
  "issues": []
}
```

字段未齐、possibleAnswers 多项/空、unsupported、超时均不能发布。审核 JSON 不是凭证本身：必须真实运行、绑定内容签名；改题面/答案/解析/来源后旧审核失效。不伪造真人审签。模型审查允许辅助，人类/字典校验的来源与边界必须如实。

### 给生成模型的核心指令（替换“覆盖第一”）

> 你为本节验证过的语言点命题。先保证语言正确、独立可答、答案唯一，再追求覆盖。只给必要题面，不复述待考结论；讲解在提交后出现。为每题明确 objective/mode/testedItems/mentionedItems。四个选项逐项代回检查，另一项成立就重写，不用“本节没讲/更贴切”排除。发现源文转写可疑就返回 pendingSource，不编造解释、不出该考点。达不到质量要求可以少出题并报告未覆盖项。保持恰好四项原标签和精确单字母答案。词义题保留明确 target；新造例句与原文引用分开标。

1. 先隐藏作答前知识点标签；这能一次消除数百题的 UI 泄题入口。
2. 先隔离 [83 道问题题](../docs/quiz-review-2026-10-07/confirmed-findings.json)，不等重新生成整个库；反馈错误的题也隔离。
3. 修语言点来源（23/32/48 等），防止坏题修完又从脏源重生。
4. 逐题修/改型，同时补上述格式、覆盖、版本及审核能力；不要只加新 prompt 后批量覆盖现库。
5. 存量按课逐步审核，未审不声称 verified。采用已验证旧题可用、新候选待审核的策略。
6. 生产数据在 `../data/toefl-lab-production/records/generated-quizzes.json`；repo 的 records 是 dev。
7. 先备份，记录输入签名；写回前复核未漂移。必须停止/协调服务写入或提供服务器安全更新入口，**运行时直接改 JSON 后再重启有被内存旧库覆盖的窗口**。
8. 原子写入成功才换内存引用、回报成功；失败保留旧库。不能保存失败仍返回生成成功。
9. 不擅自部署。本轮只写审查产物、规范和离线扫描器；实施生产更改另按部署流程进行。

## 9. 固定验收与可复跑入口

```powershell
python pipeline/audit_generated_quizzes.py docs/quiz-review-2026-10-07/production-snapshot.json --out docs/quiz-review-2026-10-07/scan --findings docs/quiz-review-2026-10-07/confirmed-findings.json
python pipeline/test_audit_generated_quizzes.py
```

- 扫描器不写输入文件、不请求 AI。覆盖所有题的结构、标签泄露候选、释义重合、范围式理由、竞争答案措辞、部分语法和重复例句。
- **退出 0 只表示未发现结构性失败，绝不是课程质量通过**。风险/已确认问题和未认证状态必须读 audit.json。
- 它不能证明所有同义项唯一，也不能自动校对全部词源/ASR。源段核验和逐题语义审核不能由此省略。
- 回归必须含以上真实失败题，还要含合法词义题、词根脚手架、should 原形题、语境线索等正例，避免“一有答案字符串就拒绝”。
- 实际浏览器验收：作答前无考点泄漏 → 选择 → 正确答案与逐项解析 → 错题本 → 坏题失效/旧版本回放。检查桌面/手机，不只测服务端 JSON。
- 当前 vince 图片讲义没有课后练，不凭空扩大生成范围。本轮优先修 48 节存量，不增题。


## 10. 逐字稿来源复核合同（2026-10-07）

新增逐字稿先执行 [逐字稿校对规范与经验库](transcript-proofreading-rules.md)，再按本节确认出题来源。该规范包含来源覆盖、错例保留、待核状态和旧管线风险；本节保留当前批次的具体约束。

- 原始 .doc/.md 不覆盖；课堂派生稿放在 `build/scripts-reviewed/ndf-01/`。本轮台账在 `docs/transcript-review-2026-10-07/correction-manifest.json`。
- 未在原始转写定位的概述不得冒充课堂逐字原文；隔离后同步剔除仅由该概述产生且正文/原始转写未匹配的语言点。不能只凭课程总讲义判断“本节已讲”。
- 检查尾段覆盖，尤其本轮第 2、6 课。原始尾段另存 `pending-tails/` 供追查；本輪已按源文補回並作本地文字修訂，仍有待聽音片段，不得宣稱全部音頻核對完成。
- 待听音、词源/历史断言未核验、错例示范、字母联想，必须与可出题的正确语言点分开。复核者注记不是老师原话，不能作为引用证据。
- `sourceReview.reviewedSha256` 绑定实际派生稿；`audioVerified:false`、`fullChineseLineReview:false` 必须保留，不得通过删除标记取得认证。
- 当前 48 课都有待确认注记，`generationReady:false`。服务端保留已有课后练缓存；新生成/强制重新生成在调用模型前返回 409。要恢复，逐课确认待审核片段、核实对应语言点并更新绑定签名及就绪状态，不能仅把字段统一改成 true。
- 本地文字复核没有外部 AI 调用，没有改写学习记录，没有批量重生成已修好的题。
