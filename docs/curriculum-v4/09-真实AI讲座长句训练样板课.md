# 样板课：在真实 AI 讲座中听住长句并回应

2026-09-30｜课程设计样稿 v0.1｜未音频校对、未真人试用、未发布

## 这节课在全程中的位置

**目标**：听一段真实讲座时，不等整句结束才翻译；先抓住主张与动作，再把后来的修饰和转折归到正确对象。完成后，学习者能用自己的英语复述讲者观点，并给出一个适用情境或保留意见。

**课程锚点**：U39「嵌套与长距离」的 K115 为主；U32 的“外层主张与内层内容”、U36 的“关系从句锁定对象”和 U03 的连续语流作为已掌握或诊断后短支援。U62「跟住讲授」是后继综合任务之一；不能因为通过这一段就直接认证 U62。U39 是一个中高级样本，不是所有学习者的第一课。成人诊断若证明基础已会，可直接进入这里；若口头输出仍弱，可并行接 U64 的自主说明训练。

**本课的真正出口**：换一个未听过的、难度相近的材料，独立说清“讲者主张什么、依据或对比是什么、哪些内容只是修饰说明”，并能表达自己的回应。原片反复听熟只算训练过程，不是该出口的证明。

## 学习者看到的完整流程

### 0. 入口：3 分钟讲清原理，或直接挑战

给还不稳的学习者一段短讲解：

> 听长句时先抓“谁在做什么、讲者正在比较什么”。听到 that / which / how 等信号，不必立刻把前一句重译；先问“后面这一块在限定哪个东西，还是在说新的判断？”当讲者用 *but in fact* 改变方向，优先更新主张。这个办法能帮助理解，不保证每句都能靠一个标记词解开；有歧义时仍要结合意义、停顿和前文。

已能无帮助完成陌生长句任务者可跳过讲解。讲解不展示本段答案。

### 1. 第一次听：原声与意义

播放候选片段，默认隐藏字幕。用户可正常重听；系统记录首次独立回答与播放次数，不以“只许听一次”制造考试压力。

屏幕只问两件事，可中文或英文简答：

1. 讲者主要在区分哪两种做事方式？他更想谈哪一种？
2. 在他说“但实际上”之后，他在修正听众的什么预期？

**作者判定口径**：要能识别“把 LLM 当搜索框、等一个现成答案”和“根据数字材料组织、呈现回应”的对比；讲者准备讨论后者可能带来的用途。可以用自己的措辞，不要求背字幕。若只听出 LLM、search 等名词但讲不清关系，记为“主题捕捉，逻辑未稳”，不判完全失败。

### 2. 定位卡点与第二次听

用户先选择或系统从回答推测障碍：声音没认出、词认识但语流跟不上、修饰对象丢失、观点转折漏听、需要背景知识。先让用户自己标一个时间点；若无法定位，系统提示关键区间。

提示逐层给，不一次泄露全文：

- 提示 1：先听“原本以为会得到什么”，再听 *but in fact* 之后讲者重新描述什么。
- 提示 2：展示两条未完成的意义线：“人们期待 ____；讲者认为它们在 ____。”
- 提示 3：显示带时间点的关键字幕，标出外层动作与修饰归属；允许查非目标词，并说明查词不等于语法失败。

揭晓时用经校对的原文解释：“被数字化的知识”这一部分是在限定 knowledge；后面“怎样呈现”是另一个动作的内容。不要让学习者从第一层修饰一路翻译到句尾，忘记讲者是在反驳“这只是搜索”。原字幕中的口误、重复和讲者现场修正要照实标记，不能静默改成教科书句子再冒充原声。

### 3. 阅读与理解，不用琐碎题凑数量

看完校对稿后只做两道有诊断价值的任务：

- **关系题**：讲者提到“已经数字化”的目的，是限定他谈的知识范围，还是声称世界上的知识已经全部数字化？说明一句依据。
- **立场题**：下列哪种复述保留了讲者的对比？A“他认为 LLM 与搜索相同”；B“他认为用户会用相似的输入方式，但背后的组织和呈现方式不同”。如认为 A/B 都不精确，允许提出自己的更准确版本。

题目答案揭晓后必须解释为何其他读法会改变原意。阅读表现与初听表现分开记，不能看完字幕再把最初听不懂的状态改成“初听已会”。

### 4. 录音复述与回应

不显示原文，给 30–60 秒准备，再录 45–90 秒英文口述：

> 向一位没听过这段讲座的同学说明：讲者为什么说 LLM 不只是搜索？你认同这个对比在什么情境下有用，或者有什么保留？

允许简洁表达，不强迫模仿讲者长句。第一次成稿之后再给反馈和重录机会，不在每个语法错误处打断。系统可显示自动转写供用户纠正；转写错误不应归为口语错误。若录音/转写不可用，临时文字回答仍能练意义与结构，但不能认证独立口语能力。

**反馈顺序**：

1. 内容：有没有保住“预期中的答案”与“讲者说的重新组织/呈现”的对比；是否把讲者观点说成无争议事实。
2. 关系：是否把修饰或转折接到正确对象上；若颠倒主张，指出具体位置。
3. 表达：是否能让同学听懂自己的解释与回应；给一两个更自然的可替换说法，保留用户原意。语音反馈须基于可靠音频能力，不能从 ASR 文本臆测发音。

例如“AI is better than search for everything”即使语法完整，也超出了这段话能支持的意思；“He thinks an LLM can organize information for the answer we ask for, so he wants us to consider uses beyond search”即使句子简单，也达成复述核心。二者都只是样例判定，不是唯一标准答案。

### 5. 新材料迁移与下一关

本片训练完成后，至少给一个**未提前展示字幕和摘要**的新家族任务：换讲者、换主题或换论证结构，仍要求抓主张、限定和转折，并做简短口述。它可以是另一段 AI/设计讲座，也可以是日常对话；发布前必须核对素材可用性。不能把原片换几个问题再算陌生迁移。

若新材料中“文字能读懂，声音没抓住”，U39 的文字结构证据可保留，听力进入 U03/U62 相关支线；若听懂但说不出，接 U64 的检索和复述支线。若主张与修饰关系都稳定，进入 U62 的较长讲授任务，并继续处理 U40/U41 等关系前置。没有后继正式内容时应明确标注制作中，不用重刷本片假装推进。

## 自编自然材料如何与真实片段配合

在真实片段之前可有一段原创对话作为低干扰练习：

> A: I thought the tool would just find an article for us.  
> B: It did find sources, but it also arranged the points around the question we asked.  
> A: So we still need to check the sources, even if the summary sounds clear?

这段材料用于把“预期—实际—保留意见”的关系听清楚，并练一次自己的回应。它不替代真实语速与现场口误；通过后进入真实片段，真实片段也不能反过来作为全部教学内容。正式制作需要原创音频、不同说话者和校对稿。

## 制作与验收清单

- 先人工听审候选区间，确认起止、字幕、噪声与关键意义；若不合适，换片而不是让学习者为坏素材反复失败。
- 给原始字幕、校对稿、时间戳、讲者/来源和修改记录分别留版本；素材题、答案和反馈必须能追溯。
- 保留首次无字幕理解、看稿后理解、首次口述、提示后的口述，以及陌生片段迁移；不能合成一个单分数。
- 检查系统能接受不同但正确的复述；讲者的技术断言不得作为语言题的唯一事实标准。
- 用一名真实学习者走完整条流程，观察是否真的从“听长句迷失”走到“理解并能独立解释”。如果只在本片变熟，下一片仍不会，修改教学，不继续堆同类题。
- 本文只证明**一条中高级学习链可以被具体设计**；不证明 72 单元已开发、语法全覆盖、音频和口语评分已实现，或本设计已有教学效果。
