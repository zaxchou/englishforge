## 1. 必须先改的目标映射

现有 D1 活动标了 O-K115-01/02/03 和 O-K184-02，但其问题与评分主要检查“保留手势／推迟语音／展厅失败／仍计划探索”。它没有要求回答 which 的所指，也没有两层 which 的对照，因此不能给 O-K115-02“which 指代范围”写成功证据。同一次总 pass 也不能自动给四个目标各写通过。

|活动|可观察的维度|允许的证据|不能顺带认证|
|---|---|---|---|
|18 的 D1 决定/原因/保留条件|原型、当前决定、原因和仍保留的计划|O-K115-03 的文字主张/限定候选证据；若补回对象定位题，才单独判断 O-K115-01|O-K115-02 的 which 范围、无字幕听力、独立口语|
|本文件 CT01|简单 which 所指|O-K115-02 的短定位线索，不等于目标全部复杂度独立达成|长句处理或听力|
|本文件 CT02|嵌套文字中的 which 对象/整体指向|O-K115-02 在当前文字复杂度的候选独立证据；首次/提示条件单记|对其他目标一并写 pass|
|本文件 CT03|当前建议与保留条件|O-K115-03 的阅读证据|O-K184 的真实讲授听力|
|本文件 CT04|英文录音中的事实关系和回应|分别评价 O-K190-02 与 O-K194-02，实际测到的项才可计|朗读、发音像美国人、全部口语已会|

建议评分输出以 `objectiveResults` 分项返回 `met / partial / unmet / unmeasured / disputed`、具体回答依据、支持条件和适用复杂度；活动级总 pass 仅控制流程。答对一个问题不能产生所有附带目标的成功事件，未问的目标为 unmeasured。

## 2. CT01：which 的短定位对照

**家族**：`projector_reference_probe`。**目标**：O-K115-02 的局部定位。无音频、无等级结论。

A. The projector, which we borrowed from the media lab, stopped working during the exhibition.

B. The projector stopped working during the exhibition, which meant that we had to change the installation.

问：A/B 的 which 各在指什么？哪一句的 which 部分在解释“发生这件事的后果”？

审核口径：A 指 projector，“从媒体实验室借来的”说明这台设备；B 指投影仪在展览中坏掉这件事，后续说明其结果。接受“设备／投影仪”和“它坏了这件事”等自己的措辞；不要求说出关系从句术语。只回答“都指 projector”不准确。只背“which 指前面”没有说明指代单位，记部分。

解释依据：[Cambridge Grammar Today 的名词指向关系从句](https://dictionary.cambridge.org/grammar/british-grammar/relative-clauses-defining-and-non-defining)与[整体分句指向](https://dictionary.cambridge.org/grammar/british-grammar/relative-clauses-referring-to-a-whole-sentence)。G1/G2 支持范围区别；**不能推广成 which 永远接最近的名词**。本轮页面直抓返回 403，公开搜索索引仍提供对应正文，与 17 中已查过的命题一致；没有声称重新通读付费语法全书。

提示 1：“被借来的是设备，还是整个事件？”；提示 2：“B 中 meant 在说明某件事产生的结果”。提示后答对只记 supported。进入陌生复杂度时换素材，不能把 A/B 换人名当独立迁移。

## 3. CT02：嵌套中保住 which 的对象和主线

**家族**：`exhibit_hardware_reference`。**目标**：O-K115-02。首次文字、收起 CT01 的例句后单独作答；本内容已对用户公开，不得用于其独立后测。

> The projector that our team borrowed from the media lab, which had recently bought new equipment, stopped working during the exhibition. The technician who checked it said that the power supply was faulty. We replaced the supply and continued the show, which meant that visitors could still see the installation. We did not replace the software, because it was running normally. The team now plans to test the borrowed hardware before the next event.

分题：

1. 第一处 which 说谁买了新设备？不要只答“前面的东西”。
2. 第二处 which 说哪件事使访客仍能看到装置？
3. 用一条短句说清首句主线；再列出附加说明，不要求逐词翻译。

逐目标口径：

- 第 1 题：媒体实验室最近购买设备。指成“投影仪买了设备”不符合此处意义。
- 第 2 题：更换电源并继续展出这件事，使访客仍可观看；仅回答“电源”未说出事件指向，记部分。
- 第 3 题：投影仪在展览中坏了；团队从实验室借设备、实验室近期购置设备属于嵌入信息。它用于解释句法关系，不因此自动给 O-K115-01/03 成功，除非分别提供独立评分合同。
- 允许中文说清关系，避免把不会英文复述误当不会阅读；后续英文产出另测。
- 阶段标准：第 1/2 题正确且能说明指向单位，才有 O-K115-02 在该复杂度的候选达成；不能凭 `projector/lab/which` 三个关键词相加判断。

## 4. CT03：避免“关键词齐就通过”和“否定里有错词就判错”

**家族**：`voice_decision_semantics`。**目标**：O-K115-03。沿用 18 的 D1 背景，只做教学与评分器验收，不新增陌生性声明。

必须接受的答案候选：

- “团队保留手势，暂缓语音。因为多人说话时这个原型在展厅里表现不好，他们想再测试；他们并未完全放弃语音。”
- “They kept the gesture controls and put voice control on hold. It failed when several groups spoke at once, but they still want to explore it.”
- “They haven't ruled out voice interaction. They will test it in the hall before deciding whether to add it.”

第三种只回答计划/限定，不能独自覆盖“当前保留了什么”子问题；应对应 partial，而不是整题通过或全错。

必须拒绝或判部分的答案候选：

- “gesture delay crowded still want”：词表齐、关系缺失。不可作为正确解释，更不能产生独立能力证据。
- “They delayed gesture control and kept voice control because the exhibition was crowded.”：角色/决定反了，即使关键词都有也不通过。
- “They permanently abandoned voice control.”：漏掉保留计划并改了决定。
- “They kept gesture control because all voice systems always fail in crowded places.”：把特定原型的场景表现过度推广。
- 空答、只复制题目、同时列正确与相反说法但没有立场：不得因命中参考词过关。

工程验收应分别有：正确改述、否定中的合法答案、角色反转、错误因果、过度推广、局部正确、无意义词袋。不确定答案进入 pending/disputed 并允许复核。低预算期可先做有限封闭关系选择/意义配对并配人工开放回答复核；不要把开放题的 `includes` 包装成语义评估器。

## 5. CT04：口述与未知追问的内容门

输入场景是原创的受控案例：

> Our team tested a navigation app on campus. The route was shorter, but several new students found the instructions hard to follow. We will revise the instructions before we recommend the app to new students.

任务：用英文向同学说清“优点、问题、下一步”；第一次录音后，再问一个未预告问题：“Would a shorter route always be a better route? Why?”

必需信息：路线较短；新生跟指示有困难；先修订指示再推荐。自由观点可赞成或反对，须回应 shorter/better 的区别并给理由。原场景没有说所有使用者都失败，不能强加这一事实。

|目标|实际评分维度|独立记录|
|---|---|---|
|O-K190-02|信息关系忠实、组织能懂、用自己的话表达|主张/原因说反则该目标 unmet，语音漂亮不能抵消|
|O-K194-02|是否直接回答未预告问题并给理由|没问追问则 unmeasured；背前面稿而不回答不能通过|
|可理解度|真人能否听懂这段录音|从可播放音频判断；无录音/坏录音未测，不能从转写臆测|
|其他语言资源|词块和语法是否支持传意|仅作具体建议，不把这段自动升级成所有语法会了|

人审必须绑定 account + attempt + activity/version + media + transcript/version，写出所评目标及片段依据。至少“内容关系”和“任务完成”不能为 0；某一维度达 2/3 不能给整段/全部目标统一通过。跟读同一文本另属声音练习，不共用自由口述证据。

## 6. 真正可学材料的交付单

本轮补的是文字/评分内容实物；以下由 Zcode 内容工作包交付，只有实物齐备才改状态：

1. D2 图书馆与 L2 博物馆脚本分别制作可播放音频，绑定版本、实际时长、校对稿和逐段意义依据。两名讲者的平行任务不得只换同一段速度。
