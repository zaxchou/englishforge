# 35 · 内容生产合同第 1 批（34 号 F1/F2/F5）

2026-10-01 ｜ 执行：Zcode ｜ 依据：[34 号复审](34-全面复审与下一批开发合同.md) §必修问题与 §下一批任务第 1 条

## F1 修复：生成器读到素材正文 + 可答性机器门

- **素材池段化**（v3-materials.json → materialsVersion 2）：每条 read 素材带 `segments[]`（segmentId/标题/原文）；`materialsForPrompt` 现在**把段正文原文放进生成提示**——生成器出题前必须读到具体文本，不再只看描述。
- **逐题绑定升级**：每个生成活动必须声明 `segmentIds`（依据哪些段）、`referenceAnswer`（参考答案 ≥8 字）、`supportingQuotes`（≥1 条支撑原句）。新门 `answerableOnMaterial`：段必须属于所选素材、**支撑句必须是段正文的逐字子串**（归一空白）。问正文没有的信息 → 引不出原文 → 整课拒收。注册函数保留全部字段（此前 materialId 在此处丢失）。
- **下发收窄**：学习者端只显示**本题声明的段**（不再整包下发而题目指向不清）；listen 类素材正文不下发（音频即素材，首听无脚本）。

## F2 修复：错误语法提示 + 目标串挂

- **提示质量门 `hintQuality`**：生成 hints 与 teachingNote 禁止机械规则话术（黑名单：加逗号的那部分/只要看到逗号/有逗号就是/多半在缩小范围/前面是主张/后面是限制/逗号后就是）——复审抓到的三条真实坏提示同型拦截。
- **目标-素材适配收窄（34-F5）**：objectiveIds 空数组语义作废；mat_g1（限定/非限定）只对 O-K115-01/02、mat_g3（对照与限制）对 O-K115-03/K184-*/O-K190-01、mat_g4（话语标记）对 O-K184-01/02。O-K115-03 课再也不能绑限定补充素材（复审 F2 例 1 的串挂路径关闭）。
- **提示守则**：每条素材带 `hintGuidance`（如"限定/非限定靠句意判断，禁止把逗号当规则"）进生成提示。
- **真实坏样本处置**：3 门已发布的真实生成课（gen-o-k115-03-vmup80utf / vmup93mc6 / vmup9n8fc）已通过 withdraw 撤出后继候选（原因注明 34 F1/F2），**学习者旧作答全部保留**；未静默修改历史题义。

## F5 修复：审核身份分字段

素材条目新增 `review: {machineCurated, selfRevised, humanReviewed, reviewer}`——当前全部 `humanReviewed: false, reviewer: null`，与注释一致：**"audited"=机器整理+自校订完成，零真人核验**，不冒充专业核验。
