## 接管与边界

用户授权 Codex 直接接手 Zcode 的开发工作。Codex 的 `sentence-forge` heartbeat 已删除；Zcode 在 coder 信号中确认停止并删除自己的调度。`agent-loop/STOP.json` 保持 stop=true。不要自动恢复无人值守循环。本轮不部署、不充值、不调用真实付费模型，不改用户真实学习数据库。

当前工作基于 [27 后续路线](27-后续开发路线与交付合同.md)、[28 学习者流程](28-学习者体验校正与前台主流程合同.md) 与 `agent-loop/tasks/000003.json`。文档名称以目录实际文件为准。Oil UI 三方向仍等待用户选择，不把这次功能改动宣称为已选定的视觉改版。

## 已实现

### D0-2 任务、媒体与测量边界

- 服务端下发 taskId，绑定账户、活动版本、活动定义哈希、诊断会话、课程版本及推荐会话。换版、同版本内容漂移、过期、错误账户/活动均拒绝。刷新复用同一任务并给 nextTake；新正文需新 take，网络重放不重复落库。
- 听力媒体分发产生 deliveryId，播放事件绑定任务、媒体版本和文件哈希。同事件重试只计一次；客户端自报 playCount 不能授权作答。旧公开媒体读取仍供审核使用，不提供输入认证。
- 关键词反馈统一为 practiceOnly，不写理解/听力/自由口语掌握事件。旧事件重算时跳过 keywordContentCheck 正分；派生状态在 savepoint 内重建，修复旧 base 正分残留，原始作答/事件保留。隔离回放回归已过，真实库迁移演练尚未完成。
- 正式测量增加按阶段取任务接口，发行前曝光与本阶段首次播放分开计算，核对实际技能、槽位评分规则、维度和复杂度。发行定义保存冻结快照，旧有效作答的正式观察不受今日过期/换版影响；首次听音可达用隔离夹具证实，生产真实留出池尚未建立。争议/未判定作答暂停计量；已有观察后来发生争议时，比较读出暂不计入，原观察保留。
- 已关闭/废弃诊断不写新作答；跨步骤重放只能接受与原正文、taskId、sessionId 一致的请求。
- WAV 校验实际 RIFF/chunk 边界、PCM 参数、数据长度。WebM 时长用 EBML VINT 与 TimecodeScale 解析，但只有时长不算可播放。浏览器先真实解码 MediaRecorder 结果再上传 PCM WAV；不能解码时保留录音草稿并报告错误。
- 口语 intent 支持 requestId 幂等，响应丢失后复用已上传资产；作答使用稳定 ID，相同重放不重复追加转写，异正文拒绝。
- 麦克风拒绝时能保存文字练习，口语仍未测；ASR/手工转写来源区分，停止录音释放设备，逐关系反馈接 API 数组。

### D1 学习流程

- 冷启动诊断/推荐自己初始化地图和样本，不依赖用户先打开地图页面。
- 今日入口区分首次开始、真实续学与没有合格后继。课程打开后隐藏重复的今日主按钮。
- 课内一次显示一个任务，明确当前步骤，提交后展示反馈，再主动进入下一步。刷新恢复服务器保存的答案、反馈和剩余步骤。页内重取过期任务保留相同材料的未提交文本/录音草稿；换版或换题面则重置相应编辑器。播放器清理旧错误与票据。
- 口述提交后刷新课包，追问解锁后才能完成；完成后保留反馈摘要，点击查看下一步回到新安排。
- 完成判定核对实际作答活动版本；按本次课程取课时间检查作答。
- 入口统一称“学习路径”，选择后地址为 #learn，刷新仍回学习路径；原旧练习入口保留。
- 成长页先显示实际完成的课程和有证据的能力记录，再显示下一步；目标 ID/复杂度审计表折叠。完成训练不等于掌握，没有伪造百分比。
- 今日安排与成长详情可自主免修熟悉目标，重新推荐；可恢复训练。免修/恢复追加事件，原能力证据不删除，免修不变成掌握。复杂度标签与听说读写分开，指代任务显示简单/嵌套负担。
- 三节样本之后诚实显示没有可用后继，不把关闭生成说成后台正在制作。

### D2 生成基础修补

- 生成活动入库保留复杂度带、默认看稿和口语降级标记，修复原先入库丢字段的问题。
- 生成输入包含本目标最近练习维度、是否仅关键词反馈、提示/看稿/查词等条件；practiceRevision 与认证 evidenceVersion 分开。
- 后端教学调整约束区分反复遗漏关系的探测、逐步撤支架、新情境探测、首次找起点。关键词成功不会自行升级难度或免修；已独立/迁移/保持的证据才允许至多一个带的难度探索。
- 新练习即使不产生认证事件，也能作废后续教学缓存。缓存用反馈记录计数避免同毫秒边界遗漏；作废课可重新缓存。命中缓存前重新核对撤回、版本、账户范围、目标归属和完成状态。
- 窗口读取先重估；生成任务等待模型期间若反馈/证据变化，输出标 superseded，不发布旧快照课程；相同目标仅复用仍匹配快照的在途任务。费用仍记入账本。
- 已发布的个体生成课也检查反馈快照：未开始的过时课不再进入未来推荐，已开始课程允许完成。旧推荐每次读出核对撤回/版本状态。
- 以上是可测试的教学约束和输入，不是“生成质量/效果已通过”。目前活动仍是关键词开放题，生成是否遵循约束需要独立输出验收。

## 不能算完成的内容

1. D0 尚未整体退出。历史普通能力重算仍有依赖当前活动定义的兼容分支，需要继续冻结版本映射与审计，正式观察已单独冻结发行定义。旧关键词证据纠正需要备份、迁移演练与前后审计；真实物理录音和失败恢复还需验收。旧无 taskId 的阅读入口仍保留兼容，不可宣称全 API 都强制发行。
2. 生产测量尚无真正不公开、未接触、可比较的新材料池。隔离夹具里的 holdout 标记及签字仅属工程测试，不能冒充真人审核或效果实验。
3. 真实材料听校未完成，633 原子草稿未事实核验；只有初始少量已核目标。不可把地图计数当完整课程覆盖。
4. 三课仍为开发样本，人审未签署；课内旧说明还有“W5待接入”等陈旧文字，需要随课程新版本整体校订，不修改历史版本伪装已经审过。
5. D2 未退出：没有证明模型生成三种画像的不同课程、遵循难度约束、自动供应合格真实材料。约束目前进提示和元数据，缺独立语义校验与素材供应。
6. 无本人连续试学数据，不能声称比旧刷题系统有效。D3/D4未开始，D5仍是草稿框架。
7. 过期任务已有页内重取并保留同材料草稿的路径；跨页面未提交录音草稿恢复仍需补齐。历史观察已使用发行快照，旧无快照任务明确拒绝正式计量，不虚构历史定义。

## Zcode 下一步，按顺序提交

### 第一批：D0-3 收口，不能拿全绿代替退出

读取本报告与26/29反例。运行已新增 scripts/ui-journey-walk.mjs（EF_PLAYWRIGHT_IMPORT 指向可用 Playwright 模块 URL），它自建测试 DB 与 localhost 服务，强制隔离路径、诊断/课程上限和超时。验证重新打开新诊断、任务过期刷新、新 take/网络重试、错误文件、麦克风拒绝、导航中断等路径。复核已实现的口语 intent/attempt 稳定身份和冻结发行定义，扩展网络失败、断页、过期恢复等路径；不因今日过期丢失旧有效观察。

先隔离复制库演练旧事件重算，输出受影响正分/状态数量和旧记录保留证据；未经备份与独立复审不触碰真人数据。完成本批后交 D0 验收报告，注明兼容入口范围。

### 第二批：D1 合格首路径与内容校订

逐条校对三课每个 prompt、教学说明、目标归属、音频意义和版本。真实材料必须注明来源/许可、片段、转写、意义依据和审签；不得模型自动补签。补足阅读→首听→看稿定位→脱稿表达→追问→反馈→下一课的一条真实路线。不要再仅增加封闭题数。

版本化替换陈旧W5说明，保留旧作答。优先交用户能连续学习一周的材料路径，仍允许未审内容诚实等待，不能用旧熟题补窗口。

### 第三批：D2 真正按反馈生成

建立已审核素材/解释/任务模板库；新事实、新音频或不确定解释进入审核。用三个相同目标但不同支持/错误画像，通过注入模型验证生成内容实际不同，并核验不是只改标题或词表。输出必须绑定素材来源、真实任务、预期观察维度和难度上限；关键词探测失败不得强认根因。

窗口维持2节完整课+最多4个候选位置，不预造万课。复核缓存、在途 job、已发布个体课程的快照约束，补地图/来源/解释版本的失效规则。验证已开始课允许完成，未开始旧课不重复进入新窗口。打通“库存低→后台生成→质量门→可用窗口→学完重估”的完整状态，失败/关闭/待审区别显示。

### 第四批：D3 本人试学，再决定扩展

提供明确试学入口和3–7天任务，记录首听理解、跟读与脱稿差别、提示依赖、追问应答和是否愿意继续。用户体验成功后再推进D4新留出对比、D5广度，不将248项测试当学习效果证据。

## 调度状态

当前是人工授权接管，不等候 Zcode 的000003结果，不伪造其结果文件，不自动恢复任何 scheduler。旧 reviews/results/tasks 保留。接收方先读 STOP 和本报告，确认工作树，遵循以上顺序；视觉方向待用户选定。
