# 43 · 完成体学习系统三方向设计

用户要求先看完成体、理解学习坐标与系统判断，再决定设计。本轮独立原型，不按现有工程进度绘制，也不修改应用代码。

打开 [完成体三方向对比页](design-complete-system/style-explorer.html)，点击画面进入单张后，可操作今天、学习地图、能力依据、成长作品与任务流程。01学习地图、02表达工作室、03成长关卡，字体、颜色与首页构图均不同。

详情、样本边界及后续交接见 [设计说明](design-complete-system/设计说明.md)。能力与作品为虚构设计情境，不是真实账户数据。未接后端、录音或真实AI判定；用户选定方向前，不自动替换应用界面。

当前推荐01解决“当前位置/为何训练”的理解障碍。用户可选择其他方向或提出具体组合偏好；后续开发保留完整信息链，不只换皮。旧 design-options-oil-ui 仍保留，本轮是新目录、新选择身份。
