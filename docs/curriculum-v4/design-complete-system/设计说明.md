# Sentence Forge 完成体设计探索 · 01

入口：[三方向对比页](style-explorer.html)。点任一画面进入单张查看，才能操作里面的学习导航；可切换桌面/手机、实际尺寸、方向，并选择与备注。也可独立打开 atlas.html / studio.html / quest.html。

## 本轮是什么

展示最终希望给学习者的产品体验，不按现有开发进度绘制。三个方向各有今天、学习地图、任务四步、能力依据、成长作品五个视图。使用同一虚构学习情境，公平比较字体、构图与配色。作品、已跨过阶段、支持条件与能力描述都是设计样本，不是用户实际画像或效果证据。

这是独立离线原型：不读真实数据库，不调用模型，没有实际音频播放/麦克风录制/语义判题，也不保存输入或更新课程。选择题的两个反馈为固定原型行为；自由文本只是对照参考，不对输入作能力判定。声音节奏图是图形构图。这里不表示这些功能已在产品实现或已经验收。

## 先看懂完成体

个人目标 → 初步定位 → 当前位置与技能依据 → 今日训练理由 → 原理/任务/提示/输出 → 新情境迁移 → 作品与条件 → 后继调整。

底层保持完整知识范围，上层只给能理解的学习坐标。六段成长旅程是导航概括，不替代72单元底层地图，也不是六个固定小课程。真实路径允许在结构和听说读写之间穿行，不强迫先把全部阅读完成才能听说。学生看的是“今天为什么练它”和可回看的作品，后台诊断标签与开发进度不作为主界面。

每个节点按技能、复杂度、支持条件分别判断。有稿理解不等于听懂，有提示完成不等于独立迁移，未测量不是0分。近期课程按需生成并审核；新反馈改变未开始内容与支持量，保留已有作品和版本，不无限重复熟题。

## 制作和验证

- 按 oil-ui 技能的设计方向与 style-explorer 流程制作；使用内置生成器，没有改比较工具模板。
- 三种 Windows 字体均核查本机文件存在；候选没有联网资源依赖，移到其他设备会按CSS回退字体。
- 桌面1280×1000、手机390×844实际截图并由主Agent看图。所有五个视图检查手机横向溢出；修正了01手机标题过度断行。
- 三方向操作了任务入口、错误/正确选择、提示、原理、参考表达、迁移、成长及未测量说明。
- 比较外壳检查并排、单张、手机、候选内部导航、选定与刷新恢复。复制可能受浏览器剪贴板权限影响，选择本身已验证。
- 减法：移除总体百分比、刷题统计、后台ID与重复动作；保留当前位置、目标、训练理由、支持条件、主动作和下一步。
- 未做独立视觉评审，用户尚未选定探索方向；不编造评分。未验证系统级200%浏览器缩放，已验证移动端重排。选定方向后可在一次深化中补独立视觉/可用性评审，而非循环代码复审；范围为一轮评阅与一轮修改，通常约10–20分钟，模型调用与时间视环境而定。

截图：atlas-desktop/mobile、studio-desktop/mobile、quest-desktop/mobile；comparison 与 map-in-explorer。preview-check.mjs / explorer-check.mjs 为本轮必要检查脚本，读设计文件、用浏览器内存模拟；不会访问应用API。

## 后续如何交给开发

先由用户选择方向与明确偏好，再把它定为信息结构/视觉基线。任何方向落地都必须交当前位置、为什么练、能力依据、任务恢复、成长作品与下一步的完整链；不能只采用配色字体而保留难懂的后台入口。设计选择不代替内容正确性或能力证据合同。
