# 53 · 真题驱动的私人托福老师：产品规划与原型合同

2026-10-02｜规划 v0.2｜当前工作为规划与原型，尚未授权进入正式托福业务开发。本文件覆盖52中旧的课程生成主线；52保留考试规则与初步备考背景。当前不交接、不恢复自动调度。

## 1. 本次已经明确的产品方向

做一个围绕托福材料学习、能持续理解本人困难的私人老师。核心题目来自用户的本地题库，AI负责看懂作答、定位疑点、讲解原题、陪练和决定下一步。课程由真题学习过程组织出来，不再靠批量生成题目充当课程。

用户已确认：**日常先独立做完一个小题组，再由老师带着分析和补弱。** 不逐题打断作答，也不要求每次先做完整套卷。整套限时检查是单独入口。

最终成功包括两个层面：符合目标的正式托福成绩；在新题上能更及时理解、更准确回应。后者提供日常成长反馈，前者以真实外部成绩验收。目标分数还没定，系统不擅自填100、110或新制某一档。

## 2. 个人情况直接决定产品行为

| 已知情况 | 产品必须体现的行为 |
|---|---|
| 成年人，通过四级，自估词汇8000–10000，基本语法学过 | 不从小学题顺刷；通过短题组看分项表现，熟悉内容可跳过 |
| 认识词但声音反应慢，听的时候会停下来翻译 | 保存首听；复盘分开检查声音识别、意义调用和整段关系；查词卡含原声与语境 |
| 长句嵌套和逻辑关系犹豫 | 允许选择原文中卡住的片段；老师演示主线及信息如何接入，再回到题意 |
| 口语多为跟读模仿，主动调用有限 | 回放自己的原音，给一个优先改进点，再录一次；还需新的无稿回答检验 |
| 背词、chunks、听写已有习惯 | 从原题提取值得练的语块；跟读、听写为补弱工具，不能替代首听正确率 |
| 每天约3–4小时，至少一年后考试 | 安排可持续周节奏，不在没有基线时强行承诺一年提到某分 |
| 喜欢有难度、提示后再试、最后讲明白 | 原始挑战→可选提示→重试→完整说明；不因错题让人永久锁关 |
| 不愿反复做已熟题，要感受到成长 | 掌握需新题证据；原题复盘减少重复，阶段成果回看实际录音、原文和独立表现 |
| 最终还要用于艺术科技硕士学习 | 题目先保持原题；补课可结合个人背景解释，不能把原题全改成AI/设计题导致偏科 |

上述词汇量、时间投入等是用户自述，不能直接推算托福分数。先用实际练习修正安排。

## 3. 为什么原来的体验偏了

原系统把能力图、判题证据和内容生产摆在学习者前面，学生很难知道为何回答、老师认为哪里有问题，以及做完后自己变强了什么。少量关系练习换了场景，并未形成一门范围和节奏都清楚的课程。

本次调整三件事：

1. 学习单位是一个有完整情境的原题组，不是单个语法标签或固定锚点。
2. 老师的工作在学生完成首次任务后变得可见：指向具体证据、解释关键原理、安排一次有目的的修复。
3. 下一次用不同原题验证修复，既给出后继内容，也能指出当前判断仍不确定。

提高视觉精致度有价值，但首页换皮不能解决这三件事。静态设计必须展示全过程及卡住时的状态，不能只做一个漂亮仪表盘。

## 4. 张俊杰框架在新系统中的位置

沿用01课稿映射和51体验审查的可持续主线：表达意图→参与者/事件→信息关系→形式选择→简洁而准确的组织。72单元保留为老师查找补课的后台知识地图，不作为学生必须走完的72级，也不作为首屏导航。

| 真题中出现的困难 | 框架怎样帮助 | 必须补充的内容与边界 |
|---|---|---|
| 长句读到中间失去主线 | 先找谁做什么，再看修饰和嵌套信息挂到哪里 | 实际句法、指代、篇章关系；不能认为所有复杂句都同一种结构 |
| 听到了词，却误解意图 | 回到这一句在对话中想做什么、谁回应谁 | 语用、弱读连读、语块及工作记忆；不能靠语法图解决全部听力问题 |
| 组句时从句语序混乱 | 将完整意思作为主句里的一个组成部分 | 具体结构限制、选词和语境；不能任意移动或删词 |
| 口语/写作只有零碎短句 | 先让主要意思完整，再加理由、例子和条件 | 任务完成、组织、语域与流利表达；复杂度不是句子越长越好 |
| 省略后听不懂 | 恢复上下文共享的信息，再观察为什么不重复 | 指代和省略的许可条件；“简单原则”不等于随便删词 |

老师不能未经检查复述词源故事或将母语者都如何思考当作语言事实。也不要求每道托福题都硬套该框架。新版听力、阅读速度和任务操作等需独立训练。

## 6. 一次日常学习的完成态

默认一个小题组为15–35分钟的首做与初次复盘，深度补弱可另外延伸。时长是设计假设，需要本人试学修正。读一段及关联题、听一段对话及关联题、一次采访回答或一封邮件都可以独立成为学习单位；不能强迫四项每天各自走完整个深度流程。

| 步骤 | 学生看到/做什么 | 系统保存/判断什么 |
|---|---|---|
| 选今天任务 | 原题主题、任务类型、为什么练、预计时长；可换题 | 选题理由来自已有表现；没有依据则称熟悉题型或摸底 |
| 独立完成 | 阅读/音频/题目或录音、写作区；提交整个小题组 | 原始答案/录音/原文、时间、是否看稿或提示、题目曝光 |
| 老师先总结 | 这次有何结果，先解决哪一个问题；可直接看解析 | 封闭题据核验答案判定；开放题给有依据的辅助反馈 |
| 定位卡点 | 学生选择没听清、意思不明、关系没懂、时间不够等；可选中片段提问 | 错因先作为假设，需要原文/音频、作答和学生确认共同支持 |
| 讲解与补练 | 指向原文/时间段，演示一个关键点；学生再试 | 使用了哪些支持；复盘正确不算首次独立正确 |
| 下一道验证 | 短补练结束后，安排未见过的另一道原题/题组 | 新题、无辅助表现是否支持迁移；当日没材料则排到之后，不假装已经验证 |
| 带着结果结束 | 今天明白什么、还卡在哪、下一次练什么及理由 | 更新短期计划；作品保存前后版本，阶段趋势独立计算 |

提交前不自动显示聊天解析、答案或听力稿。学习模式仍可主动求助/查词，系统明确标记这次用了支持，而不是拒绝救援。限时检查模式不提供这些帮助。

失败也可以结束当天：留下一个清楚的解释和下一步，比通过无限重试制造“全对”更有用。

## 7. 第一套原题怎样变成学习体验

### 听力样板：Module 1 对话第9–10题

学生版PDF第19页（印刷页18），对话涉及购物、看戏和计划时间误会。原型首屏只播匹配音频、显示两道问题和选项，不出现听力稿。整组提交后才进入老师复盘。

假设学生第10题选错：老师先指出回答与对话中的时间纠正不一致，但不直接断定“你不会条件句”。先问：那句没听清，还是听懂了每个词却没理解玩笑表达？

若听不清，回放对应短段，学生尝试复述听到的关键词；需要时再显稿、标语块和弱读。若看稿仍不懂，解释该表达在此处表示健忘，结合前后话轮确定具体忘的是哪件事。最后讲清原题正确依据以及其他选项为何不受这段支持。不得让学生背下一题答案。

原题复盘后，用另一段尚未见过的对话检查时间/意图理解。当前没有做音频匹配，原型的首要内容工作是试听并建立这一段的真实起止时间。

### 阅读样板

先用学生版实际段落和关联题作答；复盘时选中卡住的长句。老师从主线到修饰演示，要求学生用自己的话确认意思，再回到原问题的证据位置。没有证据不能把“选对了”自动归为掌握，也不能强迫每题写一篇理由。

### 写作样板：投稿故障邮件

学生版PDF第31页（印刷页30）。首次写作保留限时第一稿。老师先看题目要求是否被完成、读者能否清楚知道问题和请求，再指出一两个最妨碍表达的语言问题。学生自己修改；改动对比展示哪句从含糊变清楚。AI润色成品单独标记，不能视作学生能力提升。

### 口语样板：城市生活采访

学生版PDF第36页（印刷页35）。先按题目听问并录回答，复盘回放本人片段。内容回应、组织、可懂度和语言分别反馈；ASR不确定位置可让学生核对，不用识别错误给本人扣分。第二次重点改一项，随后需新问题的无准备回答检验，不能背好稿就认证通过。

上述案例来自用户本地文件，网页教师版的另一套主题不能替换这些题面。

## 8. AI私人老师的职责与限制

AI的主产物是个性化教学决策和有依据的解释，不是大批核心考题。

1. **讲原题。** 使用题目版本、核验答案、原文或匹配音频稿说明依据；将原题答案与自己的解析分开。来源有矛盾时暂停确认证据，不顺着假答案编故事。
2. **对话。** 支持“为什么我这个答案不行”“这句话什么意思”“我听到的是另一句”等跟进；上下文固定在当前题组，补课后返回原题。
3. **诊断。** 给出可检验假设及低成本区分办法；不同根因要有不同练法，不能一次选错便宣布整个能力缺失。
4. **补弱。** 优先复用原材料中的语块、片段和真实其他题；教学解释按需生成并缓存。现阶段不以AI自制题补足核心题库。是否允许另外生成少量迁移练习后续单独确认。
5. **评输出。** 引用本人具体片段、给一个优先改进点、解释为什么；不只贴量表、漂亮的总分或完整代写。
6. **安排下一步。** 依据独立结果、支持条件和个人反馈选真实下一题；解释安排为何变化，允许本人调整。

模型改换答案、缺稿、空录音、转写不可靠、超时、上下文串题时，都有明确失败状态。封闭判分可正常保留；AI老师失败不能丢掉作答或假称分析完成。付费模型接入、具体供应商和成本预算在技术合同阶段核验，不用MCP名字代替已接通能力。

## 9. 怎样判断能力，怎样避免无限重复

后台同时看12类新版任务及语言能力缺口。题目答错是一条观察，错因是一个待验证解释，二者分开保存。

- 首次独立、提示后、看答案后、重做、限时未见题分别记录。
- 对同一题的重试反映修复过程，不作为新的独立样本。
- 有把握跳过与实际掌握分开：本人可免刷，但标记为本人认为熟悉，后续新题自然检验。
- 掌握建议至少需要不同题组、跨日、无提示的表现；初版阈值为待校准策略，不宣称科学认证。
- 新题错了不自动清零；先检查是否难度、噪声或另一缺口导致。
- 没有足够新题时展示材料不足、需要补充；不靠把旧题换顺序伪装推进。

学生侧使用“这类新题目前能独立完成”“提示后能完成”“还需要检查”这类状态；内部目标ID、证据上限、审核标签不占据学习界面。

## 10. 一年以上备考路线：有阶段，也有调整

这是待基线修正的阶段安排，不是承诺日历，也不要求在固定月份机械升级。

| 阶段 | 重点 | 转阶段依据 |
|---|---|---|
| 起步1–2周 | 熟悉12类任务、做分项基线、确认目标；首套样板用于学习 | 四项有原始作答记录，能区分基本根因，目标及计划可解释 |
| 前期约2–4个月 | 真题精学、听辨反应、语块调用、长句与短输出并行 | 不同原题上需要的支持减少，表达与理解开始稳定 |
| 中期约4–8个月 | 专项限时、不同话题和难度、每周修正优先项 | 新材料上的速度和独立表现改善，薄弱单项不被总分掩盖 |
| 后期至考试前 | 整套节奏、关键弱项、成绩与波动、正式考试安排 | 外部可比模考接近目标且持续稳定；正式成绩最终确认 |

原型中的周计划先按3小时净学习设计，4小时为本人可选。一天安排一个深度主练＋一个短输出＋词汇/语块＋复盘，不要求每天四科都深练。现有背词、听力软件可继续使用，必要时手工记录成果；产品不把学习计时作为核心价值。

初期检查可按1–2周一次未见小题组；整套频率随基线、材料库存和复盘负担决定，不消耗完所有好材料。实际考试至少一年以后，届时再核对考试规则。

## 11. 页面与导航：先把终态说清楚

导航建议为：**今天 / 题库 / 我的进步 / 学习计划**。老师是当前题组内的持续面板，不是另一个失去上下文的万能聊天首页。

- **今天：** 当前要完成的具体题组、为什么、预计耗时、直接开始/继续；辅助区域放本周重点与后续一两个任务。未诊断就显示开始熟悉或基线，不编造薄弱项。
- **练习空间：** 原材料与作答为主；按科目呈现音频、选项、录音或编辑器。首做阶段老师收起，提交后切换到有依据的复盘。
- **老师复盘：** 本次结果、一个优先卡点、片段讲解、可选提示、再试、完整解析；对话不覆盖原文。
- **题库：** 可按科目、任务、套卷浏览；明确原题来源、版本、已见/未见及学习/检查用途。保留套卷结构，不只是散题过滤器。
- **我的进步：** 新题独立表现与支持变化、第一稿/后稿及原始录音对比；“下一次如何调整”有真实理由。继承用户选中的成长作品表达。
- **学习计划：** 本周重点、12类任务覆盖、长期阶段及可改的任务。72单元只在相关补课解释中出现。

保留用户已选的浅色成长关卡和深色表达工作室语言；两种主题呈现同一任务与流程。当前先设计学习过程，再进行视觉深化。Oil UI Pro由用户自行安装，不再等待它阻塞规划。

## 12. 原型必须展示的完整链条

先做一版能点通的代表性流程，避免再让用户只看到毛坯或错误设计基准。所有演示记录在原型说明中明确为模拟，不写入真人档案。

原型验收场景：

1. 无分数基线的人进入今天页，知道第一项任务是什么以及为何安排。
2. 先独立完成一个真实听力小题组，再看到老师；提交前没有答案泄露。
3. 一题错：走声音识别与含义理解两种复盘分支，能请求提示、再试、最后查看完整依据。
4. 看见原题回顾的进步，但没有立刻变成“新题已掌握”；下一任务明确为另一道原题。
5. 一次口语原音→片段反馈→重录，以及一篇写作第一稿→自己修改→变化解释。
6. 限时检查中没有辅助，结束后才复盘；它与日常精学明显区分。
7. 无音频、模型超时、分析有异议时，答案保存、失败原因和下一步都可见。
8. 亮/暗桌面与手机阅读时，长原文、键盘、录音和老师面板都能使用。

顺序：先结构与真实内容→本人走一遍确认→视觉与交互细化→本人再次确认→开发合同。本人如果觉得仍不像私人老师，先改原型，不以“代码都写了”为理由保留错误流程。

## 13. 材料入库与测评保留合同草案

材料数据至少区分：原文件、内容版本、套卷、模块、段落/音频、题组、题、答案、解析来源、素材类型、使用状态。相同文件去重与相同题目去重分开；不同格式可为同一题的资产，不建立多个题目库存。

- PDF/图片先识别再对照；错误的题号、缺字数量、标点、顺序或选项均会影响题意。
- 音频逐段试听，与题面和稿对应；时间戳有人工可检查依据。TTS只能另列补课声音，不能替换原音冒充原题。
- 组句保留原槽位、给定词块和干扰词，不为方便判题改变题意。
- 封闭答案保存在服务端，首做包不下发答案/解析/听力稿；全套PDF的答案页不能通过首做预览暴露。
- 开放反馈量表逐版本核验；AI反馈是辅助评价，不作为ETS正式评分。
- 未经清理的压缩包、未完成下载、无音频听力题、答案冲突材料不直接标成可用于完整检查。
- 先按可用套数及质量建立保留列表，再决定每周消耗。被教学、提示、对话引用过的材料及其同题变体不进入个人未见检查池。

先入库一套用于本人精学，另一套或其他完整未见材料留作后续检查。保留材料对本人和老师检索均隔离，不能在复盘中提前讲到。

## 14. 旧系统怎样处理，开发怎样推进

可以复用：账户和记录保存、录音上传/回放、题目状态、版本冻结、提示条件、作品对比与服务端判题基础。是否能复用由具体代码核验，不因已有测试多就默认满足新合同。

需要重设计：主导航、题组学习状态、材料导入、12类任务组件、原题复盘对话、分项能力解释、原题选择与保留池、测评规则、AI输出反馈。

暂停旧优先级：为了库存不断生成原创题、将72单元逐一铺成强制课程、用少量关系题循环刷新能力位置。旧记录原样保留；不转换成托福成绩。

| 工作包 | 交付 | 开始条件与退出条件 |
|---|---|---|
| P0 当前规划 | 本文件、材料初查、用户已确认流程与未决清单 | 当前可继续；不是开发许可 |
| P1 完成态原型 | 一个真实小题组完整闭环，口语/写作关键页面、亮暗主题 | 用户能说清怎样学，并认可体验后才进入P2 |
| P2 开发合同与技术验证 | 状态/数据/接口、导入清单、模型与音频方案、验收样例 | 原型获认可；核验真实调用质量和成本；本人确认未决核心条件 |
| P3 最小可用学习版本 | 一套精学材料＋原题复盘＋本人记录与下一题 | 真实完成首做、复盘、再试和新题检查，错误不丢数据 |
| P4 四科任务全覆盖 | 12类任务、保留池、分项检查、个人周计划 | 不是一条听力链重复换皮；逐任务内容与实际交互通过 |
| P5 长期自适应与效果观察 | 数周真实学习下的调整、未见表现趋势、外部成绩录入 | 使用真实学习反馈；材料耗尽、误诊、重复与评分漂移均可追查 |

工期不能按页面数量估算。P1先做代表流程；P2明确接入方案与实际材料工作量后才给实施估算。后续版本可分批发布，但第一批不能再以只有几个简单题却宣称完整系统的方式交付。

## 15. 开发前还需讨论的少量事项

已确认：至少一年后考试；真题为核心；AI私人老师；先独立完成小题组；原型优先；由Codex继续规划，暂不交接。

尚未确认，按顺序沟通：

1. 期望托福总分及单项要求，是否已有目标项目；没有也可先给本人期望，基线后再修正。
2. 哪些题或套卷已经练过，防止首次诊断把熟题当新题。
3. 本人是否允许AI生成少量单列的补弱/对话练习，或坚持练习任务全部来自原题；当前默认核心题与验证题都使用原题。
4. 对开放题评价的期望、是否以后需要真人校准；AI辅助反馈先能解释、能纠错，不假称正式评分。
5. 原型体验是否达到想要的私人老师效果；尚未体验不能当确认。

这些空位不能由开发Agent自行填死。目标分、已见材料和本人试学影响实际教学计划；可先做原型结构与材料整理，不能把等待答案当暂停全部工作的理由。
