# 验收清单

每条都来自第一课审计（`docs/audit-lesson-vocab-20261110.md`）里真实出过的问题，括号内是审计条目编号。逐条给出"通过 / 未通过 / 未验证"，未验证的不能算通过。

## A. 内容底稿（阶段 2）

- [ ] 组装走的是 `pipeline/lesson_notes.py` + 本课 `lesson-config.json`，不是复制改路径的第一课脚本；配置（含教师引文）留在 build/ 下的 QA 目录，没有进仓库。
- [ ] 讲义每个列项都有状态，没有漏项；重复列项保留、词卡合并。
- [ ] 规范词数、有讲解的词数、暂缓数、未定位数与整理说明里的数字一致。
- [ ] 所有引文同时精确命中逐字稿和校对记录（`word_notes.py check` 退出码 0）。
- [ ] 未定位、不确定的词没有发布老师讲解；没有借同族词的讲解代替。
- [ ] 老师讲解没有加引号冒充原话；课堂联想没有写成词源事实。
- [ ] 讲义错拼已规范，并记录了与旧词键的对应。
- [ ] 补充词单列，逐个核对了词库里是否已有，没有整批当新词。
- [ ] 用户已看过"可用老师讲解文字"。

## B. 词卡文件（阶段 4）

- [ ] `build/vocab/<lessonId>-cards.json` 的 `lessonId`、`title`、`total`、`noted` 正确，不是第一课的值。
- [ ] 词键无重复；别名词的 `key` 是旧词键、`word` 是规范拼写。
- [ ] 每张卡有基本义和分组；缺音标、缺例句、缺词根的词已列出并说明。
- [ ] 与已接入各课的重复词键已列出。

## C. 调度（阶段 5，跑测试并核对）

- [ ] 新词直接认出 3 天；看卡后认出次日。（C2）
- [ ] 已有记录的词，看卡任意次数后认出都按遗忘处理，到期与未到期都是。（C1、R2.2-1）
- [ ] 未到期旧词直接认出不写调度。
- [ ] 轮末再确认不重复结算，再确认时没认出也不二次降级。
- [ ] 同一事件 ID 重放不重复结算；换载荷重放被拒；非当前词被拒。
- [ ] 普通快照不能覆盖认读轮、复习轮会话。

## D. 第 0 天流程（阶段 5，浏览器实走）

- [ ] 课程页和背单词页横幅都能进入本课认读，刷新后停在同一个词。
- [ ] 点「认识」会显示词义核对，「其实记错了」可用。（4.2）
- [ ] 点「不认识」能看到基本义；有老师讲解的词显示讲解，没有的不显示空框。
- [ ] 「继续」后的词约 10 张后再现，不是立刻重现；轮末有打乱的再确认。（4.3）
- [ ] 分段停顿出现在词根组边界附近，标签段号正确，「今天先到这里」后进度保留。（R3.2-8、R4.2-5）
- [ ] 完成页有统计、看卡最多的词及讲解、下一次到期信息。（C5、R4.2-2）
- [ ] 卡片标签对已有记录的词显示「复习」而不是「新词」。（C6）
- [ ] 网络超时后再点任意按钮能自动恢复，不需要刷新页面。（C4）
- [ ] 认读时间计入每日学习时长。

## E. 第 1 天与第 3 天（阶段 5，用隔离记录推时间）

- [ ] 横幅显示当天待再认数量，点进去是复习轮，不是昨天的完成页。（R2.2-2）
- [ ] 认读没过完时，到期词仍然先进复习轮。（R3.2-2）
- [ ] 横幅文案与点进去的轮次一致。（R4.2-1）
- [ ] 到期量超过 40 时，完成页有「继续再认（还剩 N 词）」。（R3.2-4）
- [ ] 复习轮做完、认读没过完时，完成页有「继续认读」。（R4.2-3）
- [ ] 离开认读页后，横幅和课程页徽标更新为最新状态。（R3.2-3）
- [ ] 返回旧背单词页，不会把刚评过的本课词当新词再出。（C3）

## F. 与其他模块的隔离（阶段 5）

- [ ] 旧背单词页的队列和计数不含本课词。
- [ ] 旧页不发未上课的万词班新词。
- [ ] 万词班未上课时，EnglishPod 新词块仍正常发出。（R3.2-1）
- [ ] 认读界面打开时，旧页的定时器和重渲染不会把界面顶掉。

## G. 多课（接第二课及之后）

- [ ] 打开另一课时词卡、标题、计数、分段都是该课的，不是上一课的。（R3.2-5）
- [ ] 两课同时有到期词时，横幅的选择符合到期优先。
- [ ] 跨课重复词只结算一次；到期数是否重复计入已知并说明。
- [ ] 已有课的会话、到期数在新课发布前后没有变化。

## H. 发布（阶段 6）

- [ ] shell 脚本是 LF。
- [ ] 发布包含新词卡文件。
- [ ] 正式 records 已备份。
- [ ] health 版本正确；`/api/vocab/lessons` 列出新课，词数与有讲解数正确。
- [ ] 新课会话为空，没有替用户开局。
