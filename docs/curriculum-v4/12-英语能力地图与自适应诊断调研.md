# 英语能力地图与自适应诊断：MCP 调研及 PRD 修订

2026-09-30｜研究与产品设计 v0.1｜不安装第三方 MCP，不修改应用代码

## 1. 用户提出的目标

新学习者来到系统，先用少量真实任务迅速建立**暂定能力画像**；题目从容易进入，随表现迅速升难，卡住时自动换题区分到底是哪个知识、声音识别、词汇调用或表达能力有缺口。系统据此拼出近期课程，教完再用陌生任务复测；新证据可能发现另一个缺口，课程继续改。理想状态是学习者像跟一位了解完整英语体系的老师上课，而不是替系统维护题库。

“几道题后知道下一步怎么教”可以成为产品目标；“几道题后知道所有英语知识的精确边界”不能作为真实承诺。初次画像带置信度和未测区域，随学习持续更新。某一道错题不是知识边界的充分证据，某一道对题也不能证明掌握；要用能区分原因的平行任务进一步核对。

本次公开资料和当前可用工具清单中，**未发现一个已经可调用且经验证的“英语大师级总诊断 MCP”**。这是调研范围内的发现，不等于断言互联网上绝对不存在。MCP 是接入工具或数据的协议形式；若底层没有可信目标图、测题和效度证据，换成 MCP 也不会自动获得专家判断。现阶段不安装候选组件；后续可用小规模对照试验判断 Tutor MCP 的调度能力是否值得复用。候选版本、可调用工具、与浏览器架构的接线及准入门槛已在 [16 MCP 与语音选型](16-MCP与语音能力选型-接入决策.md) 中固定；本研究表不代表已完成实装。外部框架用于对照覆盖、难度和真实能力出口，本项目仍需建立自己可审计的英语能力图。

## 3. 本产品的“英语大师地图”应由哪些层组成

1. **语言结构层**：张俊杰 21 份逐字稿提供的解释入口和现有 72 单元/216 目标组；继续拆成可独立判断的原子目标，补齐未覆盖的形式、意义、使用条件与例外。事实以可靠语法资料核验，不把“简单原则”当没有边界的公理。
2. **加工层**：声音到词义、连续语流、长句即时解析、词汇/语块主动检索、篇章与记忆负担。它解释“文字能懂，听课跟不上”之类落差，不能混入语法正确率。
3. **交际层**：叙述、解释、澄清、回应、辩论、复述、协作与礼貌程度；按生活、课堂、艺术科技项目和面试场景组织。
4. **技能与证据层**：听、说、读、写、互动分别存目标、复杂度、支撑条件和证据；标出“未测、暂定会、独立展示、跨场景迁移、延迟保持”。
5. **前置与替代路径层**：定义学习某目标真正需要什么；已会可免修，某一模态卡住可转支线而其他模态继续。单一线性主线供用户体验，底层是允许分支汇合的图。

CEFR/GSE 作为外部能力出口与难度对照；English Profile 作为英语习得顺序与用法参考；张俊杰的课程思维作为教学解释风格；综合语法资料作为语言事实核验。它们不能互相替代，也不直接构成个人诊断结果。

## 4. 入口测试怎样自动找“卡点”

**第一段：快速定位，约 5–10 分钟的设计目标。** 从一两个成人可接受、但不幼稚的简单任务进入；答对就跨较大难度，答错则在附近和前置目标中找更能区分原因的任务。先给“下一步最值得学什么”的暂定判断，并公开未测区域，不一上来宣布完整 CEFR 等级。用户可选择继续补听说读写样本，第一天可分段完成。

**第二段：辨别同一种错误的不同原因。** 例：书面长句判断错，先用熟词短句、相近结构但更短的句子和意义问题，区分关系从句归属、词义、注意负担或题目歧义。若文字正确、原声音频错误，就针对语流/熟词声音再测，不能自动把语法降级。若能听懂却不能复述，测试语块检索和自主输出。题目至少有不同家族，不只是换名词。

**第三段：停止条件与后续继续测。** 当证据足够选出接下来几节合适课程，诊断就先停止，让用户真正开始学；后面的课程继续收集证据。初期采用可解释的分支规则和不确定性标记。等题目有足够作答数据后，才可研究校准项目难度与自适应测量模型；不能把 AI 猜出的“难度 7/10”直接当经过统计校准的题目参数。

最初几题可以逐渐变难，但对有四级基础和高被动词汇量的用户，不能花几十题证明他认识主谓宾。难度不仅是语法层级，也包括音频速度、讲者、词汇熟悉度、关系隐含度、输出自由度与互动压力。

## 5. 从诊断到拼图课程

引擎先挑“对用户目标重要、未有证据、前置满足、补上后能打开更多后继”的缺口；再选择教法、任务类型和生成素材。每块拼图要有缺口来源、预期改变、成功证据和失败后去向。

例如用户可读懂带多层从句的 AI 文章，却两次无字幕漏听 `but` 后的结论、口述只说出关键词。系统不发“关系从句基础 20 题”，而先给一节不同讲者的真实短讲授与转折捕捉，再给简短的口述组织支线。后测换陌生材料；若转折已能听出但口述仍卡，保留听力成就，只调整输出路线。这个例子展示的是可审核的决策方法，不假设当前产品已能自动做到。

## 6. 全自动化的验收标准

“全自动”不是完全没有质量边界。正常情况下学习者只需做题、听、说、读、写和查看反馈；系统后台自动选目标、生成、校验、安排和重规划。对高不确定内容保留审核与回退机制，但不把用户变成内容管理员。

第一次产品验证必须证明：
- 几个初始任务能产生**有不确定性标注**的合理下一课，而不是伪装为完整水平证书；
- 同一表面错误的不同根因会导致不同诊断题和不同后续课程；
- 已会内容能快速跳过，后续陌生任务若证明缺口再局部补足；
- 文字会、声音卡和理解会、输出卡能被分开对待；
- 生成的解释、答案、音频字幕与评分可追溯，坏题不把学习者降级；
- 两周后在新材料上的听懂、复述、互动或写作表现优于起点，且改善不只来自做熟原题。

因此下一步核心不是寻找一个“装上就懂英语”的 MCP，而是把这张地图、诊断题合同、学习者证据和后端决策闭环做成可检验的系统。
