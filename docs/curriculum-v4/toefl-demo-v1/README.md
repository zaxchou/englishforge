## 制作与来源
Oil UI Pro 已安装并读取。此次远程入口在用户明确授权仅发送产品摘要后返回新的19.90元待支付状态，未取得压缩设计指令；没有付款、没有第二次提交。不能称本原型由Pro成功执行。为继续完成用户任务，采用本地Oil UI 0.10的方向卡和官方对比页生成器。个人画像/教材文件/录音未发送。
使用既有用户选择的亮色成长方向及暗色表达方向重新组织，不使用过去选错的首页作为基准。

素材来自本地学生版练习第1套：
- PDF第10页：日常邮件原文、11/12题；手动按原页转录，未做全部PDF入库。
- PDF第19页：对话与9/10题；首做不显示稿，复盘可回看原页。
- PDF第29/31/36页：重复/邮件/采访的页面参考，重复首做不提供原文页。
- conversation/interview/repeat.mp4分别从同目录原始MP3生成AAC衍生；不声称已核验所有音频或正式时间段。
原型里的答案依据仅作本地页面教学展示，正式版必须服务端判分并防下发答案。

## 已经检查的范围
Chrome headless实际运行两方向四科，共8条首做→复盘→重试→进步链；空作答拒绝、首做无解析、录音导入回放元素、笔记在换页前捕获、观看与能力分离、回课程后保持阶段。见 [verification.json](verification.json)。
截图：1280×900、390×844、200%页面缩放；已查看两种首页、手机浅色、深色复盘及200%截图，未发现所查页面横向溢出。不是所有页面/浏览器/硬件可用性的完整认证。
录音导入检查使用音频文件作为控件测试，不当成用户真实回答。麦克风真实录制、权限允许分支、ASR、声学评价、用户学习效果未验收；对比页已改为静态候选。独立原型支持录音入口或导入音频，麦克风实录仍未验收。
现有原型只有代表流程，尚未提供全部12题型、真正限时套卷、所有模型超时分支或已绑定的后继新题。后继界面如实显示等待绑定。
对比页内嵌候选实测脚本存在，但指针/键盘操作未触发任务按钮；未查明宿主/沙箱根因，改用静态比较＋独立交互入口，不伪称嵌入流程通过。仅主Agent自检，没有独立设计评审；方向探索先给本人选择。三处基本反馈：按下按钮、步骤切换、内容进入；尊重减少动态效果。没有录制三段动效证据，不用静态截图宣称动效验收。

## 设计方向卡
| 项 | 学习路线 | 专注工作室 |
|---|---|---|
| 品类 | 成人分科学习工具 | 成人练习与反馈工作区 |
| 首屏 | 通栏任务顺序，单个主任务 | 侧边任务轨，主区任务工作台 |
| 取舍依据 | 本人最需要知道当前在哪与下一步 | 长文/录音/稿件需要少切换 |
| 字体 | Segoe UI / 微软雅黑，步骤数字Georgia | Georgia展示 / Calibri与微软雅黑正文 |
| 色彩 | 淡蓝、海军蓝、行动蓝 | 深绿灰、暖白、浅绿行动 |
| 记忆点 | 首做→复盘→新题验证的明确位置 | 材料与本人回应在手边 |
| 不采用 | 游戏经验值、虚构掌握率 | 万能聊天首页、复杂后台指标 |
