# 学习闭环与调度规则

以 2026-11-10.r10 的实现为准。实现在 `lesson-vocab.mjs`（纯逻辑状态机）、`server.mjs` 的 `/api/vocab/lesson*` 端点、`web/lesson-vocab-ui.js`、`web/index.html` 的横幅与旧页隔离部分。改动这些文件后，回来更新本文件。

## 学习者每天看到什么

| 时间 | 入口 | 内容 |
| --- | --- | --- |
| 第 0 天，课后 | 课程页「过本课单词」或背单词页横幅 | 全词认读。按词根组边界分三段，段间可停，进度保存 |
| 第 1 天 | 横幅「今天 N 词待再认」 | 复习轮：昨天看卡后才认出的词 |
| 第 3 天 | 同上 | 复习轮：直接认出的词。每轮最多 40 词，完成页可「继续再认」 |
| 之后 | 同上 | 到期词继续走复习轮，间隔按 SM-2 延长 |

认读没过完又有到期词时，先进复习轮，完成页有「继续认读（还剩 N 词）」。

## 一张卡的流程

1. 正面只有英文、音标、发音。两个按钮：认识、不认识。
2. 点「认识」：显示基本义核对。认读轮 2.5 秒后自动通过，可点「其实记错了」；复习轮和「再确认」的词不自动通过。
3. 点「不认识」：展开基本义、老师讲解（有才显示）、词根宇宙（可选展开）、例句。点「继续」后约 10 张再出现。
4. 看过卡才认出的词，本轮末尾打乱顺序再确认一次。
5. 全部认出后进完成页：统计、本轮看卡最多的词及其老师讲解、明日到期数。复习轮完成页另有本轮词根族回忆面板。

## 调度结算

只在点「认识」时结算一次。`tries` 是本轮里该词看卡的次数。

| 词的状态 | 直接认出（tries=0） | 看卡后认出（tries≥1） |
| --- | --- | --- |
| 新词 | 3 天后复习 | 次日复习 |
| 已有记录，已到期 | 按「良好」延长间隔 | 按遗忘：间隔重置 1 天，ease 减 0.2 |
| 已有记录，未到期 | 不写调度 | 按遗忘：同上 |
| 轮末再确认 | 不再写调度 | 不再写调度 |

「不认识」和「继续」本身不改调度。看老师讲解、打开词根宇宙不算评分。3 天是用户定的产品策略。

## 必须保持的不变量

1. 一词一份长期记忆：课级评分只写 `records.vocab[key]`，与旧背单词同一键空间。
2. 会话与记忆分开：认读轮存 `records.vocabLesson[lessonId]`，复习轮存 `records.vocabLessonReview[lessonId]`，两者并存。普通快照不能覆盖这两处，也不能覆盖 `vocab`、`vocabEvents`、`vocabDays`。
3. 服务端是唯一真源：每次评分在同一次落盘里改会话和调度；先校验后写入；同一事件 ID 重放不重复结算，课级事件也登记进全局 `vocabEvents`。
4. 课级词归课级：有词卡的课，其词不在旧背单词页的队列和计数里出现，到期只走复习轮。
5. 新词只从上过的课进来：旧页只发已标记上课的万词班词；EnglishPod 词块不受此限制（批次 `kind==='eplod'`）。
6. 到期优先：`/start` 的顺序是未完成的复习轮、有到期词则新开复习轮、认读轮。横幅的选课和文案顺序必须与此一致。
7. 评分后前端要把服务端返回的状态并入本地缓存；离开认读页要强制刷新课程概览。任何评分错误都重新同步会话，不让界面停在报错上。
8. 别名词：讲义错拼对外展示规范拼写，存储沿用旧词键，历史记忆不断。

## 复习轮的编排

- 同词根族相邻，族按族内最早到期时间排序，同时到期的族随机。
- 单轮上限 40 词，只管条数。
- 同一个词出现在两课词卡里时，哪一课的复习轮先遇到就在哪里结算，另一处未到期不写。

## 还没有的环节
