## 3. 待人工 / 待资源清单（诚实边界）

1. **模型账户余额不足（402 Insufficient Balance）**：AI 草稿拆解（216 组）与按需生成的真实模型调用均无法执行。工具已就绪且可断点续跑：充值后 `node scripts/decompose-ledger.mjs`（每次落盘，重跑跳过已完成组）。**本报告不含任何 AI 生成的未核验内容**——这与 13 §3「不可用 AI 自动填满后宣称全覆盖」一致。
2. **人审签署人缺位**：课程包 signLesson、口语 oral_reviews 的真人复核流程已实现，但当前无第二人签署；所有内容带 human_review=pending + dev_only/开发样本标记，机器不可代签（trigger/白名单强制）。
3. **音频未制作**：L2/L4 原声、正式保留题（18 的 L4 已公开不陌生）、双讲者平行版本——P3 内容门槛，未完成前听力课如实显示「文字模拟、听力证据未测」。
4. **本人试学未发生**：P6 门槛。两周陌生任务前后测、数周延迟复核——试学工具包就绪，等用户开始学习。
5. **多人化前置**：全 API 无身份鉴权（15 §8 承认的开发期边界：账户切换不是安全认证）；withdraw/publish/sign 需 confirm/reviewer 字段防误触，公开推广前另建身份与访问控制。
6. **已知小缺口**（各审核 P2 未尽项，已如实标注在代码注释/指标 note）：生成指标缺撤回率与等待时间；时长约束依赖客户端自报（真实设备试产后冻结）；素材授权门暂无分发路径可拦（真实素材为零）；transcriptReliability 待接真 ASR 后由服务端给出。
