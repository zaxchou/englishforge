# 课后练（AI 出题）生成规则与防复发闸门

> 2026-10-07 固化。每一次规则都来自真实事故，改生成链路前先读这份文件；
> 新增规则时在"事故"一栏补上来源，没有事故来源的规则不要加（防过度工程）。

## 生成铁律（system prompt，server.mjs `genQuizInner`）

1. **正确答案唯一**：题干判定条件必须只有正确选项满足；同义近义竞争词不得同现（huge≈very large、shrub=bush 类多解事故）。
2. **判错理由必须是真实的语言学错误**：严禁"本节没讲/未重点讲解/超纲"（9 课 q22 事故）。
3. 每选项 note 说清含义与为何对/错；题型混合 root/collocation/meaning/cloze。
4. 干扰项允许讲义外（词义题本应多样）；但**答案词必须能在逐字稿找到**（`traceOK` 溯源）。

## 机械闸门（`parseQuiz`，全部拒收级）

- 选项文本归一化后两两不同（29/33 课重复选项事故）。
- 答案必须在 A-D 内。
- 禁词：`未重点讲解|本节未讲|未在本节|更直接对应本节`（覆盖式判错）。
- 题干与解析里的英文考察词溯源（`traceOK`，只查答案词；全中文问答放行）。

## 生成后处理

- **跨批题干去重**：归一化题干（去空白/标点/空格线）已存在即丢弃——覆盖补漏轮是重复的主要来源（07 课 collaborate×3 事故）。
- **讲解释级**（`aiGradeTaught`）：清单分批 120 项/批判 taught/mentioned；失败回退全清单。
- **生成后判级**（`gradeTiers`）：逐题判 core/ext，前端拆「课堂复习/扩展挑战」双入口；**必须先给题目赋 id 再判级**（否则 AI 对 undefined 编号判级会全量误标 ext，r7 事故）。失败全按 core。
- 批次 JSON 截断：max_tokens 7800、单批失败自动重试一次。

## 数据一致性

- 生产题库 = NAS `data/toefl-lab-production/records/generated-quizzes.json`（repo 的 records/ 只是本地 dev 库，两者不同步——排查生产必须读卷）。
- 改题/去重一律：备份到 records/backups/ → 原子写回（tmp+mv）→ deploy sync 重启容器重载。
- qid（`gen/<course>/<lessonNo>/quiz/<n>`）独立于数组位置：删题安全，重排不安全。

## 已知边界（设计如此，不是 bug）

- 大清单课（讲过项 >150）物理覆盖不完 → 60 题上限，剩余靠词表墙兜底。
- 判级/分级失败一律回退宽松侧（全 core / 全清单）——宁可多给，不阻断出题。
- vince 课纯图片讲义无文字层 → 无课后练（GEN_COURSE 仅 ndf-01）。
