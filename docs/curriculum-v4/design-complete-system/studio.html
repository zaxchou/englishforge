排练室里的决定

Although our voice prototype worked well in a quiet studio, it failed during a crowded exhibition. We kept the gesture controls, but we delayed voice control until we could test it with visitors in the exhibition hall.

团队作出的决定是什么？

把新情况归到原来的原理里

先找主线，再看
它在哪种条件下成立。

“在安静工作室有效”和“在人多的展厅失灵”可以同时成立。although 承认前一个事实，同时引出后一个事实，没有把方案直接否定。

最后的决定是 kept 与 delayed。until we could test… 指明推迟的时间边界。原文没有保证测试之后一定采用，也没有说永久取消。

判断靠对象、场景、决定和条件的真实关系。but 后面并不总是限制。

一种自然表达

We kept gesture control, but postponed voice control because it failed in the crowded exhibition. We need to test it with visitors before taking the next step.

对照你的作品：保留与推迟的对象是否说对？有没有把暂时推迟说成永久取消？理解你的表达要看意思和关系，词表只能提供线索。
