# 查一个词，记住一组词：可操作探索

本地试用：[http://127.0.0.1:8075/](http://127.0.0.1:8075/)

这轮推荐一个查词入口、四个连续阶段：**词义与用法 → 构词来由 → 词根与词族 → 回忆与应用**。单字与查词按用户澄清合为同一个入口，词根作为快捷探索入口。

推荐先查 **contradict**，沿每页主要下一步看完整路径；再试 **unpredictable**，比较它的现代逐层构词图。

## 路径为何这样安排

普通用户先拿到意思和例句，再把语义与构词材料联系起来。当前单词贯穿阅读、来由与图谱阶段；点击图中其他词可继续查，看见词性和词义怎样变化。英文答案在主动回忆时隐藏，练完回到词族或开始下一个词。

“发明者视角”体现在：从表达需求出发，理解已有成分怎样组合表达一个意思。例如用“相反、反对”与“说”理解“反驳”。这是一种作者组织的理解线索，历史形式和借入史另列在来源追踪中。

## 当前能体验什么

- 一个搜索框查已有单词、根形或中文根义；完整单词命中优先打开词义，用根形搜索或词根目录可直接找成员。
- contradict / contradiction / contradictory：已逐词核过的三词材料、角色明确的成分块、三条各自借入英语的路径、主动回忆及原创语境题。
- predict / predictable / unpredictable：来源支持的两层现代派生关系，1道主动回忆＋2道语境应用。
- 点击图中词条继续查，展开根下全部已收录相关词；dict 根73成员与 digit 根分开。
- 其他已发布学习词可以查词义与现有课堂线索。缺少完整构词材料时不补造词故事；只有回忆题时，导航、页头和结尾都按“词义回忆”表述。
- 当前页刷新保留本轮草稿或反馈，浏览器返回恢复词条阶段；未知词和网络失败有明确结果与重试。

## 内容边界

反驳三词的构词图按当前已签署模板编排，**不是全库自动生成历史图谱的能力**。其历史路径是三词共享拉丁来源，不能看成英语 contradict 依次历史派生出另外两词。predict 两条现代派生边则来自正式事实图，方向按形成层级呈现为 predict → predictable → unpredictable。

当前 dict 学习档案：`baecb8471f939190b46eb27974fd8d08a322646e00c7cb3b30fc7627204da7ab`。三词现有 source 的快照、修订号、SHA与摘录做了本地只读核对，未重新联网核验。出处为 English Wiktionary contributors，CC-BY-SA-4.0，界面可打开固定修订和原文片段。

词条学习例句复用已有档案中的原创或课程例句并标注类型；新语境题是本轮原创英文。浏览器朗读不使用付费TTS，音效未作真机验收。

本轮为独立探索页面，没有替换正式词典入口，没有写入生产学习记录或现有SM-2调度。练习位置只保存在当前浏览器标签的sessionStorage，结果只表示本轮作答，不表示长期掌握。

## 启动

在项目根执行：

```sh
node prototypes/word-journey-20261111/server.cjs
```

默认只监听本机8075；可用环境变量 `WORD_JOURNEY_PORT` 更改端口。API复用既有只读词根服务，依赖本地 `build/root-universe/` 已发布内容。HTML、CSS、JS和服务文件均在本目录，与正式页面隔离。
