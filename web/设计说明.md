# TOEFL Lab · 设计说明

单文件 HTML 原型，零依赖，双击可运行。

> **本轮**：优化 UI（整理档）+ 加三个新模块（视频课 / 计时 / 持久化）。
> 规范体检结论：**规范本身有问题**（9 种字号 / 17 种间距 / 11px 用 19 次），
> 偶然的默认值全部重新决定，目标是给这个产品建立一套干净的尺度。

## 用户任务

豪哥是英语高频练习者，已有 11 套完整真题（968 题）。他要的不是"题库浏览器"，
而是能**逐步专项训练**的刷题工具 —— 整套模拟只是考试时的选项，不是日常入口。
核心诉求：四科可拆开练、已做过的题有明确标识、做完自动判分、错题自动进错题本、
口语写作有 AI 批改、**dashboard 要能看到足够多的信息**。

## 选定方向

**材质 × 环境：磨砂玻璃 × 深夜书房**

磨砂只用在需要分层的表面（顶栏、任务页头），正文区与内容卡片保持实色。
层次靠玻璃，文字阅读不靠玻璃。

调性：安静、精致、疏密适中。禁止圆形裁剪、光晕、渐变、装饰性阴影。

## 视觉尺度（这轮的核心改动）

### 字号：9 档 → 5 档，每档一个角色

| 变量 | 值 | 角色 |
|---|---|---|
| `--f1` | 20px | 区块主标题（大数字） |
| `--f2` | 15px | 卡片标题 |
| `--f3` | 13px | 正文、选项、数据 |
| `--f4` | 12px | 次要说明、元信息 |
| `--f5` | 11px | 标签、统计、辅助标记 |

**改前的问题**：区块标题 15px vs 正文 14px 只差 1px，灰底上完全看不出主次
（豪哥截图指出「按题型挑」「待复习」都太重且没层级）。
11/12/13 三档只差 1–2px，却承担了说明、次要、标签、统计四种角色。

### 间距：17 档 → 6 档，4px 基准

`--s1` 4px / `--s2` 8px / `--s3` 12px / `--s4` 16px / `--s5` 24px / `--s6` 32px

改前 7/9/11/13/15/18/44 都是一次性取值，没有节奏。

**落实方式**：写脚本把 62 处 `font-size` 和 66 处 `padding/margin/gap`
映射到语义变量，**硬编码归零**。不是逐个手改，是收拢到变量。

### 区块头：标题 + 计数并排

```
专项训练                    4 类题型     ← 标题 20px + 计数 11px 同一行
按遗忘曲线排序 · 1/3/7/14 天             ← 说明降为 12px
```

计数是次要信息，不该另起一行抢注意力。

## 验收重点

1. **17 项交互断言全通过**，零 JS 报错
2. 结构检查：style 配平 1/1、CSS 括号平衡、标签全匹配、零硬编码字号
3. **headless Chrome 逐页截图核对**（唯一能抓出渲染问题的方式）
4. 数据自洽：套题卡标签与百分比一致（已完成=100% / 未开始=0% / 进行中=0-99%）

## 修过的 bug

| 症状 | 真因 |
|---|---|
| 首屏一片白 | 拼接文件时留下**嵌套 `<style>`**，浏览器把第二层当文本 |
| 判分反馈不出现 | 批量中文化时把**变量名 `done`** 也翻译了 → ReferenceError |
| 套题卡「已完成」但四科有 0 | `setStat` 分母用了"做过的题数"而非"该科总题数" |
| 总览「未开始」永远是 0 | `PROG` 只存有记录的题，未开始的题不在表里 → 要用总量减 |
| 专项总览卡不显示 | `h +=` 之后又写 `h =`，把总览覆盖掉了 |
| 出现「整套练习s」 | 批量替换时 `</p>` 的 `p` 被吃掉 |

## 双栏视频课（v6 重构）

**UE 问题**：v5 是"课程列表在上、播放器在下"的长页面 —— 每切一节都要把页面
拉回播放器位置，豪哥反馈"每次都要拉到下面，UE 很不好"。

**双栏解法**：
- **左栏 340px sticky**：系列分组（vince 托福课 / 新D方 新托福全套）→ 课程 → 章节三级树。
  课程项带进度细条 + `已看/总节数`；章节项带状态标记（✓ 已看完 / 呼吸圆点 = 播放中 / 灰点 = 未看）。
- **右栏 sticky 播放器**：16:9 深色播放区 + 大播放键 + 控制条（标记看完 / 进度 / 下一节），
  下方本课程进度条 + 讲义 + "看完练"关联条。
- **切节零滚动**：点左右任何章节，只有右栏内容换，页面不跳。

**点课程名右侧联动**：展开课程时自动切到"第一个未看完的节"（全看完回第 1 节）。
之前只展开不切换 → 豪哥点"阅读"右侧不动，以为坏了。

### 状态分层语言（这轮确立的规则）

| 层级 | 颜色 | 用在 |
|---|---|---|
| hover | `--hover` rgba(0,0,0,.045) | 鼠标悬停，弱反馈 |
| 选中/当前 | `--sunk` #E9E8E5 + 结构标记 | 当前节/当前课程/当前 tab，强状态 |

之前行 hover 与选中**同用 sunk** —— hover 到选中项旁边时两片灰底连成一块，
分不清哪个是当前（豪哥："highlight 连一起我看不懂"）。

### 修过的自洽错误（隐蔽 bug）

`csKey(c,i){ return c.id+'-'+i }` 期望课程对象，但**所有调用处传的都是 `c.id`**
（字符串）→ 键全变成 `"undefined-0"`。写入/读取同错所以**自洽**：测试全过、
页面能跑，但所有课程的第 N 节共享同一个键 —— 看完 04 第 0 节，v1 第 0 节也
显示已看完。截图里 vince 课显示 2/2 全看完才暴露。

**教训：自洽的错误最难发现 —— 断言会过，只有跨实体的数据对比才能抓出。**
修法：csKey 改收 id 字符串 + 加载时清理 `undefined-` 开头的坏键。

## 新增模块

### 视频课（与真题分开，讲义联动 + 关联练题）

素材实况（扫了 NAS）：
- `新D方新托福全套\01~07` 各科目 **.mov** 14–48 节，**共约 200 节**，每科配 PDF 讲义
- `vince托福课\` 17 个 mp4，**每个都有同名 PPTX**
- 文件名自带章节号和标题（`04 2.3 学术讲座术语与解释考点.mov`），可直接解析成章节结构

页面结构：课程列表（7 门）→ 展开章节 → 播放区 + 讲义 + **关联练题条**。
`COURSES[].lessons[].link` 指向专项训练的题型，实现"看完这节 → 练对应题"。
进度存 `localStorage.tfl_cs`。

### 计时与倒计时

托福 2024 真实时间限制：

| 科目 | 上限 | 说明 |
|---|---|---|
| 听力 Section 1+2 | 75 min | 含 10 min 转场 |
| 阅读 | 60 min | |
| 写作（独立） | 30 min | 综合写作与阅读共用时段 |
| 口语 | 20 min | |

做题页顶部计时条：本套已用 / 本题用时 / **剩余倒计时**（<10min 变黄，<2min 变红）/
暂停 / 底部进度条。每题用时按 `套题/科目/题号` 存 `localStorage.tfl_qt`。

### 学习记录持久化

| 键 | 内容 |
|---|---|
| `tfl_prog` | 每题状态（todo/doing/done/wrong + n + right） |
| `tfl_qt` | 每题累计用时 |
| `tfl_cs` | 视频课观看进度 |
| `tfl_study` | 学习时长（今日/累计/连续天数） |

**立即落盘 + beforeunload 强制写**。原来用 400ms 防抖，刷新会丢最后一条 —— 改成同步写。
预置数据不覆盖已有记录（`if(PROG[k]) continue`）。

Dashboard 新增两个区块：
- **学习时长** — 做题计时 / 视频课 / 今日，3 卡 + 连续天数
- **每题用时** — 按科目对比建议用时，超线标红

## 剩余项

- 视频课为占位播放器，未接真实 .mov（Z: 网络盘跨域 + .mov 需转码或用 <video>）
- 讲义为示意内容，未接真实 PDF/PPTX
- AI 批改为前端模拟，未接后端
- 音频是模拟进度条，未接真实 m4a（Z: 网络盘需处理跨域）
- 口语录音只模拟波形，未接 MediaRecorder
- 账号系统未做（记录按浏览器 localStorage，换设备不同步）
- 题库数据为结构真实、题面示意：套题编号、四科题量、音频数、覆盖率取自
  `电子档-2026-10-03J` 真实统计；做题页 14 题为演示样例

## 验证方式（三层，缺一层就会漏）

1. `node --check` — 只查语法，**查不出 ReferenceError**
2. DOM 桩 + 逐项断言 — 查逻辑
3. **headless Chrome 截图** — 查真实渲染

```bash
"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu \
  --window-size=1280,1100 --virtual-time-budget=4000 --screenshot=out.png "file:///path/index.html"
```

`--virtual-time-budget` 必须加，否则截到的是动画未完成的中间态。
